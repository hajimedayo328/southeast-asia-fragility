# notes/32 — 1997アジア危機を persistent homology (TDA) で実データ検証

**日付**: 2026-06-23
**コード**: `src/h_petri/tda/tda_crisis_1997.py`, `tda_robustness.py`
**出力**: `src/h_petri/tda/tda_1997_h1.json`, `tda_1997_h1.png`, `indices_close.csv`(cache)

## 目的

temporal タブ §P6-C で「手で値を置いた」Čech H¹ タイムライン（1996/12=0 → 1997/7=4 → 1997/12=6）と、
その撤回後の結論「**市場可視の H¹ は発火前に動かない＝同時指標**」が、
**実データ由来の persistent homology でも現象として再現するか**を独立手法で検証する。

### 重要な但し書き（過大主張・捏造防止）
- 圏論版 H¹ = 各国 Trust 値の sheaf 上の Čech コホモロジー（手置き・ネットワーク上の穴）。
- 本検証の H1 = 各国日次リターンを点とする Vietoris–Rips 複体の persistent H1（幾何的な穴）。
- **同じ "H1" だが構成は別物**。主張するのは「両方とも崩壊前に立つか」という現象の一致だけ。
- 値はすべて実データから計算したもののみ。前兆が出なければ「出なかった」と書く。

## データ・手法

- 指数（Yahoo Finance, auto-adjust, 実取得）: TH `^SET.BK` / ID `^JKSE` / KR `^KS11` /
  MY `^KLSE` / PH `PSEI.PS` / SG `^STI` / HK `^HSI`。
- 共通期間 **1996-12-12 〜 1999-12-28（N=650 取引日）**（KR/TH が1996-12開始のため）。
- 手法（Gidea–Katz, arXiv:1703.04385 に倣う）: 各日 = 7指数の対数リターンの点（R⁷）。
  長さ w 取引日のスライディング窓で w 点の点群 → `ripser` で H1 → 寿命(death−birth)の L2 ノルム。

## 結果（実測のみ）

### 中心結果
- 崩壊前（1997 上半期, 平穏）H1-L2 平均 = **0.0089** → 危機期（97/7–98/2）= **0.0169** = **1.90倍**。
- **ブロックbootstrap（B=2000, block=10）: 比 1.90, 95%CI [1.49, 2.44], 1 を除外**。

### 頑健性
- **window 長 30/40/50/70/100**: 比 1.62〜1.97（全て >1）。**ピークは全条件で崩壊後**（1998-02〜12）。
- **指標**: L2寿命 比1.90 / 最大寿命 比1.94 / **ループ本数 比0.84（危機期に減少）**。
  → 危機期は「穴の**数**は減るが各穴が**大きく**なる」＝市場の一体化（co-movement 強化）の描像。
- **国セット**（TH/KR を除く5カ国 ID/MY/PH/SG/HK）: 比 1.62, 前兆 NO。

### 前兆性 = 無し（頑健）
- ピークは**全 window・全指標・全国セットで崩壊後**（タイ変動相場制移行 1997-07-02 より後）。
- 立ち上がりはタイ単独崩壊（7月）でなく**地域伝染期（香港10月・韓国12月）から**。
- → persistent H1 は **1997 危機の同時〜遅行指標であって前兆ではない**。

## 解釈

- 市場リターンのトポロジーは危機の**同時指標**。これは圏論版 sheaf H¹ の（盛らずに撤回した）結論
  「市場可視の H¹ は同時指標」を、**独立手法 + 実データ + CI で再現**した。手法横断の頑健性。
- 圏論版は「ファンダメンタルズ（短期外債/準備, Guidotti–Greenspan）を入れて初めて前兆化（名目0/調整6）」だった。
  本TDAも同じ構造を示唆：**純粋な市場データのトポロジーは前兆を持たない**。前兆にはファンダが要る。

## 限界

- 比 1.90 は「危機期は市場が荒れる→相関構造が変わる」と不可分。新規情報量は限定的。
- **前兆性が無い** = 早期警戒指標としては弱い。Gidea–Katz が米国（2000/2008）で示した「リード約34日」は
  この**アジア7指数版では再現しなかった**。
- 危機/平穏の窓の境界（1997-07-02 / 1998-03-01）は固定。change-point の定量検出はしていない（目視 + 区間平均）。
- ループ本数が逆向き（0.84）= 指標選択に一部依存。「穴の大きさ」と「穴の数」で符号が違う点は隠さない。

## 次の候補

1. ファンダメンタルズ（短期外債/準備）を TDA 入力に足し、圏論版と同じく前兆化するか。
2. change-point 検出で立ち上がり時点を定量化（目視の「10月から」を数値で）。
3. persim の正確な persistence landscape ノルムで L2 簡易指標を置換し結論が動かないか。

## 追記（同日）— vol標準化で 1.90倍は「ボラ由来」と判明 → negative result

`tda_precursor.py` で中身を分解した。**結論: 上の 1.90倍はトポロジー固有でなくボラティリティ増の反映**。
上の「中心結果/解釈」は、この追記で格下げされる。

- **vol標準化**: 各国リターンを20日ローリングvolで割ってから同じTDA → 危機/平穏比 = **0.90（消える）**。
  raw の 1.90倍は「危機期は市場が荒れる(vol↑)」の反映で、**方向の co-movement 構造には危機/平穏で差が無い**。
- **change-point**: L2 が平穏baseline(mean+2sd=0.0124)を最初に超えるのは 1997-06-10（崩壊22日前）だが**単発**。
  **持続ブレイクアウト(10日連続)は 1997-09-23（崩壊83日後）** = 持続的な立ち上がりは崩壊後。前兆性は弱い/無い。

### 訂正された結論
市場リターンのトポロジー(persistent H1)は、1997危機に対して **vol 以上の情報をほとんど持たない**。
「同時指標」ですらトポロジー固有でなくボラの反映。**位相幾何を市場データ単体に当てても新規情報は出ない**
（圏論版が「市場可視 H¹ は同時指標、前兆にはファンダ＝短期外債/準備が要る」と言ったのと同じ壁に、独立手法でも到達）。

### 価値（negative だが本物）
出た 1.90倍を自分で vol標準化にかけて潰した = このプロジェクトの作法（盛りの自己検出）の実演。
「TDA を当てたら危機指標が出た」で止めず、中身がボラだと確かめた。**2手法（圏論 sheaf H¹ / TDA persistent H1）が
独立に「市場データのトポロジー単体では危機を語れない」へ収束**したことが、この方向の本当の結論。

## さらに追記 — ファンダ層別（短期外債/準備）でも前兆化せず → 方向クローズ

`tda_fundamental.py`。圏論版の前兆化（脆弱 V={KR,ID,TH} vs 健全 S={MY,PH,SG} を
短期外債/準備比率で層別）を TDA で試した。

- V群も S群も raw 比 ~1.9倍だが、**vol標準化で消える**（V 1.09 / S 0.70）。
- 崩壊前 V/S = 1.61（raw, 脆弱が高い）も **vol標準化で 0.89＝消える**。脆弱国は単にボラが高いだけ。
- V群の持続ブレイクアウトは崩壊 82日後＝前兆なし。

### 副産物の洞察（negative から得た一番価値ある結論）
**圏論版の H¹ 前兆化の源は「短期外債/準備というマクロ年次値そのもの」であって、トポロジー手法
（sheaf / persistent homology）の力ではなかった。** 手法を圏論→TDA に替えても、入力が市場データである限り
前兆は出ない。前兆を出していたのは手法でなく、入れたマクロ・ファンダ値だった。

### この方向の結論
位相幾何 × 東南アジア「市場」データは、**4分析（基本・robustness・vol分解・ファンダ層別）すべてで
vol 止まり**に収束。誠実にクローズする。トポロジー手法に固有の危機シグナルは、このデータからは出ない。
