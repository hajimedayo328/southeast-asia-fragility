# Notes 28 — H¹ 前兆化の偽陽性分析(文献ベース)

**日付**: 2026-06-14
**対象**: §5.5(notes/25 の H¹ 前兆化、`sheaf/h1_leading.py`)が自認した最大の穴
「偽陽性分析未実施」を、文献ベースで埋める。
**コード**: `src/h_petri/empirical/false_positive_test.py` → `docs/data/false_positive_test.json`

## 出発点 — §5.5 の主張と穴

§5.5 は、危機に先行する観測量「短期外債/外貨準備(1997年6月末、RBA RDP9805 Table 9:
KR 3.0 / ID 1.6 / TH 1.1 / MY 0.6 / PH 0.7)」を Guidotti–Greenspan ルール(比率≤1で健全)で
Trust に接続し、名目 H¹=0 → 実態調整 H¹=6、発火前に「脆弱/健全の境界」に不整合が立つ、とした。
自認した穴は3つ: ①retrodiction(G-G は1999年=危機後に定式化)②1エピソードのみ
③**偽陽性分析未実施**。本ノートは③に取り組む。

なお土台の数値(KR3.0…)は RBA RDP9805 Table 9「Liquidity and Currency Mismatch Variables」
(end June 1997)と**逐語一致を確認**(2026-06-14)。捏造ではない。

## (A) この指標は EWS 文献でどう評価されているか

| 文献 | 報告 | 出典(裏取り済 2026-06-14) |
|---|---|---|
| Frankel & Saravelos 2012 | 80本超レビューで準備と実質為替が2大先行指標。準備指標は短期外債比が最有効(5指標中4つが5%有意) | J. Int. Econ. 87(2):216–231 / NBER w16047 / CEPR vox |
| Kaminsky–Lizondo–Reinhart 1998 | signals approach の15指標に**短期外債/準備は無い**。準備を短期外債で測るとデータ点が激減し有意性が落ちる(原典記述) | IMF Staff Papers 45(1) |
| Berg–Borensztein–Pattillo 2005 | EWS の域外性能は mixed、長期1モデルのみが当てずっぽうに勝つ。単一閾値は誤報が常 | IMF Staff Papers 52(3) |

→ **両刃**。回帰系レビューでは「最有用な準備指標」(§5.5 に追い風)。しかし signals approach は
この指標を落としているので、**較正済みの noise-to-signal 比が存在しない** = §5.5 は
「低偽陽性率」という数字を文献から借りられない。そして一般論として単一閾値 EWS は域外で誤報が多い。

## (B) エピソード内の混同行列 — マレーシアという偽陰性

§5.5 自身の5カ国で、シグナル=比率>1、結果=1998年 実質一人当たり GDP 下落、で採点:

| 国 | 比率 | signal | 1998 GDP | 判定 |
|---|---|---|---|---|
| KR | 3.0 | ✓ | −8% | TP |
| ID | 1.6 | ✓ | −16% | TP |
| TH | 1.1 | ✓ | −12% | TP |
| PH | 0.7 | − | −3% | TN |
| **MY** | **0.6** | **−** | **−10%** | **FN(偽陰性)** |

TP=3 / FP=0 / FN=1 / TN=1、偽陰性率 25%。**マレーシア**は比率0.6(「健全」signal)なのに
GDP −10%(韓国 −8% より深い)。重傷閾値 −5〜−9% で頑健(−9% でようやく韓国が FP 化するが、
それは閾値を厳しくしすぎた人為性を示すだけ)。

GDP 数値は二次的代表値(出所で ±数%。総 GDP だとマレーシア −7.4% 等)。ただし
**順序 ID>TH>MY≈KR≫PH は頑健**で、混同行列は順序で決まる。

## 解釈 — 「指標が間違い」ではなく「射程外のチャネル」

マレーシアは資本規制(1998/9)で IMF 支援を受けずに済んだ。比率0.6 は
**対外短期流動性が本当に健全だった**ことを正しく示している。だが −10% の打撃は
**資産バブル・資本逃避という別チャネル**から来た。G-G ルールが見るのは対外流動性チャネル
だけなので、これを取り逃す。つまり §5.5 の「H¹ 境界=被害濃淡」は**対外流動性に限れば妥当、
危機被害全体では MY が反例**。

## 結論 — §5.5 をさらに格下げ

- (a)/(b)/(c) 格付けで、H¹ 前兆化は **retrodiction + 1エピソード** に加え、
  **単一チャネル指標で in-sample 偽陰性あり** を明記。「当時予言できた」は引き続き主張しない。
- 真の**偽陽性**(比率>1 だが危機**なし**)はこの5カ国では測れない(全員が危機当事国)。
  測るには**非危機国・年のパネル**が要る=未着手の自前パネル(残課題)。
- 文献ベース版で言えるのは: この指標は「有用だが万能でなく、専用の偽陽性率は文献に無く、
  自エピソード内ですら偽陰性を持つ」。§5.5 の慎重な格付けはむしろ**正当化された**。
