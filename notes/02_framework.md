# 02. 圏論的枠組み — 「便利と不可視コストの随伴」

**ステータス**: draft v1

## 中心仮説

**「すべての便利には、見えない右随伴が貼り付いている」**

数学的には: 随伴 `L ⊣ R` が成立するとき、L (左随伴 = 便利・自由) と R (右随伴 = 不可視コスト) は必ずペアで現れる。

| L (見える便利) | R (見えないコスト) |
|---|---|
| 速い経路 (リープフロッグ) | 信頼の単一ノード集中 |
| 海外労働で家族を養える | 義理経済の重圧 |
| コンパクト都市の効率 | 1橋落ちで街分断 |
| AI依存の効率化 | 思考力の外部化 |
| プラットフォーム経済 | GAFA崩壊で全滅 |
| 抗生物質の即効性 | 耐性菌 |
| 観光モノカルチャー | コロナで街死 |

→ 全部同じ構造。これを圏論で書く。

## 基底圏

Jia-Floridi 2025 と同じ **Rel の部分2-圏** を採用:
- 0-cell: 集合 (機能、ノード、状態)
- 1-cell: 二項関係 (依存、フロー)
- 2-cell: 関係の包含 ⊆ (本プロジェクトでは「両立可能性」に緩める)

## 主要対象

| 記号 | 集合 | 意味 |
|---|---|---|
| `S` | インフラ需要状況 (国×時刻) | 入力 |
| `R_adv` | 先進国経路の中間リソース | 銀行/ATM/送電線 |
| `R_leap` | リープフロッグ中間リソース | SIM/モバイル基地局/太陽光 |
| `W` | ゴール世界 (機能実現状態) | 出力 |

## 主要射 (例: 機能 Pay)

```
σ_adv : S → BankAccount → ATM → Wire → W (送金完了)
σ_leap: S → SIM → MobileMoney → W (送金完了)
```

平行射として 𝒞 上に並ぶ。両者の関係を 2-cell で書く。

## リープフロッグ可能性

**定義 (leapfroggability)**:
機能 X はリープフロッグ可能 ⇔ `σ_adv^X` と `σ_leap^X` の両立可能性 2-cell が存在し、
かつ経路ノード集合が disjoint。

両立可能性 α は **共通coarsening (粗化)** で定義:
```
∃ τ. σ_adv ⊆ τ ∧ σ_leap ⊆ τ
```

これは Jia-Floridi 2025 の `LLM ⊆ human` (片方向包含) を緩めた版。
リープフロッグの本質「先進国に届かないゴールにも届く」が表現できる。

## Grothendieck Construction

国の圏 𝓒 = ASEAN10 上に、機能と国でindex された関手:
```
F : 𝓒 → Cat
F(c) = 国 c の実装圏 𝓘_c
```

Grothendieck construction `∫F = 𝓘`、射影 `p: 𝓘 → 𝓒` は fibration。

各ファイバー 𝓘_c は:
- JP (参考): `σ_adv` 主、`σ_leap` 退化
- VN: `σ_adv` と `σ_leap^Pay` 両方存在
- SG: `σ_adv` 主、`σ_leap` あまりなし (リープフロッグ不要)

## Heyting代数による「証拠ベース」記述

普通の集合論では:
- 「VNはモバイル送金を実装している」 → True/False の二値

Heyting代数 (直観主義) では:
- 「実装している証拠が確認されている」
- 「実装していない証拠が確認されている」
- **「まだ分かってない」**

これにより:
- グラフの漏れを明示的に許容できる
- 「全部列挙してない」を弱点ではなく **設計** にできる
- Jia (2024) Heyting Algebra in Flat Origami と直結

## 「不可視コスト」を圏論で扱う

各ノード/エッジに **2層**の構造を持たせる:

- **可視層 (L)**: 普通のグラフ。普及率、フロー量、頻度
- **不可視層 (R)**: 同じノード集合上に別エッジ。「信頼の借り」「義理の蓄積」「冗長喪失」

L側だけ見ると「便利」、R側を見ると「コスト」。
**L と R は随伴ペア**として数学的に同期している。

可視化では:
- 上層に L のグラフ (太いエッジ)
- 下層に R のグラフ (赤いエッジ)
- ボタン1個で災害を発火 → L層が切れる → R層に転嫁

## 中心定理候補 (v1未証明)

**Theorem (leapfroggability判定)**:
ファイバー `𝓘_c` で機能 X がリープフロッグ可能であるための必要十分条件は、
平行射 `σ_adv, σ_leap` の経路 disjoint テストが構成的に判定可能であること。

**Theorem (随伴の不可分性)**:
任意の関手 `L: 𝓐 → 𝓑` が右随伴を持つとき、その右随伴 `R` は同型を除いて一意。
よって「便利」L が定義されると「不可視コスト」R が**自動的に決まる**。

これらは v2 で詰める。
