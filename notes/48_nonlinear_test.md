# 関数形の検定: 天井は情報の限界かモデルの限界か (2026-07-20・実行前に固定)

## 文献の足場 (WebSearchで実在確認済み)

- Beutel, List & von Schweinitz (2019, J. Financial Stability 45, 100693)
  "Does machine learning help us predict banking crises?":
  MLはin-sample適合は高いがOOSの再帰評価ではロジットに負ける。頑健
- 対立側: Fouliard-Howell-Rey系はMLの優位を報告(危機種別・設定が異なる)

## 問い

「GG+TFが特徴量空間の天井(+0.03弱)」の主張は、これまで**線形(ランク加法)ロジット**
でしか検証していない。批判者の当然の一手「モデルが弱いだけでは?」を裁く。

## 構成 (事前固定・チューニング禁止)

- 情報集合は完全に同一: GG-ECDF, TF_m-ECDF の2変数のみ。h=6, train<2000/test>=2000
- 基準: 既定のECDFロジット
- **主検定モデル: GradientBoosting (n_estimators=200, max_depth=3, lr=0.05,
  subsample=0.8, random_state=42)** — この設定で一発。testを見た再調整は禁止
- 全報告(バー適用外): RandomForest(500本, depth6, leaf50) / 2Dビン表(10x10,
  経験ベイズ縮約) / 交互作用項つきロジット(GG×TF積)
- 学習は全trainデータ(ケースコントロール不要、sklearnは不均衡OK・両者同条件)
  ※基準ロジットも同一データで再学習して条件を揃える
- **合格 = ΔAUC(GBM−ロジット)>=+0.03 かつ 国ブロックCIが0を除外**

## 読み (どちらでも答え)

- 合格 → 天井はモデルの限界だった。非線形・交互作用の構造を掘る新章が開く
- 不合格 → **天井は情報の限界**で確定(Beutel et al.と整合)。「2変数の中身は
  線形ランクで使い切っている」= 国際水準の批判に事前回答できる

## 結果 (2026-07-20 実行・verified_results.txt正本)

| モデル(同一情報集合) | test AUC |
|---|---|
| **ECDFロジット(基準)** | **0.6517** |
| 交互作用つきロジット | 0.6544 (+0.003) |
| RandomForest | 0.6432 (−0.009) |
| 2Dビン表(EB縮約) | 0.6344 (−0.017) |
| GradientBoosting(主検定) | 0.6294 (−0.022) |

主検定 GBM−logit = **−0.0222 CI[−0.046, −0.001]** → 不合格どころか**有意に劣化**。

- Beutel-List-von Schweinitz (2019, JFS)の「MLはOOSでロジットに負ける」が
  うちの通貨危機パネルでそのまま再現された
- 交互作用項(+0.003)も無意味 = レーン掛け算仮説の棄却(RoR 0.70)と整合
- **結論: 天井(+0.03弱)は情報の限界で確定。モデルを強くしても壊れない**。
  ハイパラは事前固定・一発勝負なので「チューニング不足」の言い訳は当方には無いが、
  逆に「チューニングすればGBMも並ぶ」可能性はある——ただし並んでも天井主張は不変
