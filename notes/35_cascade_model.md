# 奥: カスケード生成模型 v1 設計書 (2026-07-13・実装前に固定)

## 目的

Phase 1-2 の発見(空洞化・貿易火事・翌年ピーク・局所性)を1つの動く機構に統一し、
回帰では原理的に不可能な出力(反実仮想・波の統計の再現)を得る。
予測精度の向上は目的ではない(たぶん上がらない。それで構わない)。

## 模型 v1 (最小構成・実装前に固定)

- 状態: f_{i,t} ∈ {0,1} (国iが t 年に通貨危機状態か)
- 対象: GGパネルの113カ国(内生)。それ以外の約80カ国は観測値を外生境界条件として使う
- 発火(onset): 非危機の国 i が t+1 に危機入りする確率
    λ_{i,t} = σ( a + b·rank_t(x_{i,t}) + c·rank_t((P_t f_t)_i) )
  x=借金÷貯金(観測値・外生), P_t=前年貿易シェア行列, rank_t=その年の断面順位(ECDF)
- 持続: 危機状態は毎年確率 ρ で継続、1-ρ で終息(幾何分布)
- ペトリネット的読み: トークン=準備。x が高い=トークン薄い。攻撃遷移の発火率が
  自トークンと隣接ノードの炎上に依存。v1 では準備の時間発展は外生(観測値)に固定し、
  危機状態の伝播だけを内生化する(v2 で準備消費を内生化する余地)

## 推定 (pre-2000 のみ)

- (a,b,c): 観測データの1歩先尤度で最尤推定(実装はECDFロジスティックと同型)
- ρ: pre-2000 の危機スペル長から直接推定 (継続年数の割合)

## 合格基準 (事前固定・これを動かさない)

シミュレーション: 1976年の観測状態から出発、x と P は観測値、f を内生的に伝播。
500回反復。年間発生件数の過分散指数 D = Var/Mean (観測値 7.96 [113カ国パネルでの
対応値は実装時に観測から再計算して固定]) と年間発生件数の分布を比較。

1. **(a1) 生成的妥当性**: 観測の過分散指数が、フル模型のシミュレーション分布の
   中央90%区間に入ること
2. **(a2) 伝染項の必要性**: c=0 に固定して再推定した無伝染模型では、観測の過分散指数が
   その90%区間の外に出ること (= 波の群発は伝染項なしでは説明できない、が本命の主張)
3. **(b) 予測を壊さない**: 1歩先 λ の test(>=2000) AUC が GG+TF ロジスティック(k=1)の
   -0.03 以内
4. **(c) 反実仮想を1本**: タイ1997の発火を消した反実仮想で、韓国・インドネシア・
   マレーシアの1997-98発火確率の変化を反復シミュレーションのCIつきで出す

## 失敗の定義も先に書く

- (a1)不合格: 「この模型クラスでは波を説明できない」→ negative として記録、v2 の動機
- (a1)合格・(a2)も逆に合格してしまう(無伝染でも波が出る): 「波は共通ショックで説明可能、
  伝染項は波の説明には不要」→ 貿易火事の解釈を「個別リスクの再配分」に弱める重要な修正

## v1 結果 (2026-07-13・verified_results.txt末尾が正本)

- 推定: 伝染項の重み1.82(強い)、GG 1.55、継続率ρ=0.61(危機は平均約2.5年続く)
- 観測(同一宇宙=内生国のみで再計算): 平均5.5件/年、過分散 **D=3.29**
- フル模型500回: D の90%帯 [0.93, 1.89](中央値1.38) → **(a1) FAIL**
- 無伝染模型: D帯 [0.67, 1.32] → **(a2) PASS**(伝染なしでは波ゼロ=Poisson近傍)
- **読み: 伝染項は波を「作る」が(1.4>0.9)、観測の波(3.3)の半分も説明できない。
  欠けている主犯候補 = 共通ショック(FRB利上げ・ドル循環・資源価格)——全国同時に叩く
  外生要因の項が模型にない**。危機群発の古典的分解「伝染 vs 共通ショック」で言えば、
  この結果は共通ショック優位を示唆
- v1の既知の粗: 発火率の較正ズレ(シミュ7.9件/年 vs 観測5.5件/年、fitとsimの
  タイミング規約の1年ズレ由来の疑い)。v2で修正すること
- **v2の設計方針**: 年共通ショック項 η_t (全国共通のストレス因子)を追加し、
  観測Dを再現した上で「波の何%が伝染由来か」を分解する——それ自体が発表価値のある量
  (Kaminsky-Reinhart 2000 "crises, contagion, confusion" の問いの定量版)

## v2 設計 (2026-07-13・実行前に固定)

- 修正: タイミング規約を fit と一致させる(t年の特徴量→t+1年の発火)
- 追加: λ_{i,t} = σ( z_{i,t} + δ + η_t ), η_t ~ N(0,τ) 全国共通・年i.i.d.
- **較正(2モーメントのみ)**: δ を平均発火数/年に、τ を過分散Dに合わせる(フル模型で)
- **検証(較正に使わないモーメント・事前固定)**:
  (v1') 最大年間発火数(最悪の波のサイズ)が90%帯に入る
  (v2') 年間発火数のラグ1自己相関が90%帯に入る
- **分解(主目的)**: 同じδ,τ*で2×2(伝染on/off × 嵐on/off)の中央値Dを出し、
  過剰分散(D-1)への寄与を分解。「嵐が点火し伝染が増幅する」の増幅率を定量化
- **反実仮想**: THA1997の発火を消す→KOR/IDN/MYSの1997-98発火確率の変化(反復CIつき)

## v2 結果 (2026-07-13・verified_results.txt末尾が正本)

- 較正: τ=0.7, δ=-0.50 (平均5.4件/年とD=3.08に適合)。伝染重み1.89・GG 1.60・ρ=0.61
- **検証(較正外モーメント)**: 最大波サイズ obs=18 ∈ [13,31] → **PASS** /
  ラグ1自己相関 obs=0.37 ∉ [-0.17,0.29] → **FAIL**。
  診断: 現実の嵐は複数年続く(82-83年、97-98年)が、v2のη_tは年i.i.d.で記憶がない。
  v3はAR(1)のηで直せる見込み(未実施)
- **主目的の分解(2×2, 過剰分散D-1)**:
  なし -0.03 / 伝染のみ +0.41 / 嵐のみ +2.21 / フル +2.51
  → **波の8〜9割は嵐(共通ショック)、伝染の上乗せは1〜2割**(この模型クラス・このパネルで)
- **総合の絵(Phase 2と整合)**: 「嵐が波を作り(いつ・何件)、貿易の火事が中の犠牲者を選ぶ(誰が)」。
  TFが個国予測で最強なのと、波の主因が嵐なのは矛盾しない——別のレベルの問い
- **反実仮想(THA1997を消す, N=4000, 共通乱数)**:
  KOR/MYS = **判定不能**(当時の両国はWDI債務統計に不在=パネル外。0.000は欠測であり値ではない)。
  評価可能な隣国: IDN 13.6%→13.4% (Δ-0.2pp) / PHL 9.8%→9.7% (Δ-0.2pp)。
  **模型上、タイ単体の除去はほぼ無影響**——「タイは台風の最初の雨粒であって、台風の原因ではない」。
  分解結果(嵐優位)と整合。留保: 年次解像度+順位ベース伝染項は単一国効果を薄める構造なので、
  この小ささは模型クラス依存の可能性あり
- 合格基準の総括: (a1)v2で実質達成(較正後) / 検証2本中1本PASS / (b)未実施 / (c)実施済み

## v3 設計 (2026-07-13・実行前に固定)

- 変更点: η_t = φ·η_{t-1} + ε_t, ε~N(0,σ) (AR(1)嵐・定常初期化)。他はv2と同一
- **較正(3モーメント)**: δ→平均, σ→過分散D, φ→ラグ1自己相関 (φ∈{0.3,0.5,0.7}から選択)
- **検証(較正外・事前固定)**: (i)最大年間発火数 (ii)凪の年の数(発火≤1の年数) が90%帯に入る
- (b)の扱い: カスケードの1歩先予測核はPhase 2のロジスティックと同型なので(b)は構成上
  ほぼ恒等的に成立。正直にその旨を記録し、独立の検定として扱わない

## v3 結果 (2026-07-13) — **生成的妥当性に到達**

- 較正: φ=0.5(嵐の年持続率50%)、σ=0.556、δ=-0.471。
  targeted: D 3.05 vs 観測3.08 ✓ / lag1 0.29 vs 0.37 (グリッド内最良)
- **検証(較正に使っていないモーメント・両方PASS)**:
  (i) 最大波サイズ: 観測18 ∈ [12,28] → PASS
  (ii) 凪の年数(発火≤1): 観測7 ∈ [2,11] → PASS
- **v1→v2→v3の弧**: 伝染だけでは波が出ない(v1) → 嵐を足すと波は出るが記憶がない(v2)
  → 嵐に半減期約1年の持続性を入れると、46年の危機史の質感(平均・波の強さ・粘り・
  最大波・凪)を、合わせていない統計まで含めて再現(v3)。
- **最終的な機構の絵**: 「持続する嵐(共通ショック)が波を作り、貿易の火事が犠牲者を選び、
  各国の家計簿が個体の耐性を決める」。分解: 波の8-9割=嵐、1-2割=伝染。
  単一国の除去(THA1997)はほぼ無影響=タイは最初の雨粒であって台風の原因ではない
- 残り(未実施): 準備消費の内生化(真のペトリネット化=v4)

## 嵐の正体の同定 (2026-07-13・STORM-ID・探索的)

- 方法: 各年の実発生数を模型(家計簿+貿易火事)が説明できない残差として η̂_t を逆算
- **顔検査: 完璧に近い**。嵐トップ6年 = 1998(アジア/ロシア/LTCM), 1982(中南米債務),
  1994(テキーラ/CFA切下げ), 2009(世界金融危機), 2016(資源安後遺症), 1990(湾岸/ソ連末期)
  ——**教科書の世界危機年を、教えていないのに全部言い当てた**
- 観測要因との相関(全ペア報告・n≈45): ドル高(2年) r=+0.27, 油価下落(2年) r=-0.24,
  FF金利水準 r=+0.16 — **全て筋書き通りの方向だが、どれも有意水準に届かず**(n.s.)
- FF金利2年変化は r=-0.25(逆符号): 利下げ局面と嵐が併走 = FRBが世界危機に**反応して**
  緩和する逆因果の混入と読むのが自然
- **正直な結論: 嵐は実在し歴史の名場面と一致するが、46点の年次系列では単一の観測変数に
  統計的に還元できない。おそらくドル・資源・リスクセンチメントの複合体**。
  月次化(データ拡充)か複合指標の構築が次の手だが、探索的段階として一旦ここで留める

## STORM-FORMULA 設計 (2026-07-13・実行前に固定)

- 仮説: 嵐=グローバル金融サイクル(米金融政策+世界リスク選好の単一因子。Rey系の文献、
  書誌は執筆時に裏取り)。式: η_t = γ'·G_t + ε_t、G_t = [ドル2年変化, 油価2年変化,
  FF水準, VIX年平均(1990+のみ)]
- 検証①: η̂_t を G_t に回帰、R²を報告(記述)。全期間版(VIXなし)とVIX期(1991+)版
- 検証②(本命・事前固定): 嵐を「観測駆動 η_t = γ'·G_t + 縮小ノイズ」に差し替えて
  500回シミュレーション。**観測の D と lag1 が90%帯に入れば「嵐に式が付いた」、
  外れれば「嵐には観測不能成分が残る」**。どちらも結論として記録

## STORM-FORMULA 結果 (2026-07-13) — **式は棄却、嵐の大半は未同定のまま**

- 回帰: R²=0.154(全期間45年, ドル/油/FF) / 0.263(VIX期30年, +VIX)。
  係数の符号は全て理論どおり(ドル高+, 油安-, VIX+)——**方向は支持、説明力は15〜26%止まり**
- 生成テスト: 観測駆動の嵐に差し替えると、(A)決定論版は D が過大([3.49,5.83] vs 観測3.14)
  で不合格(lag1は合格)、(B)残差ノイズ付きは大幅過大([7.2,23.8])で不合格。
  **判定: 嵐は「ドル+資源+米金利+VIX」の線形式には還元できない**
- 興味深い機構メモ: 式駆動の嵐は自由AR(1)嵐より「分散あたりの群発」が強く出る
  (ドルサイクルは低周波=ゆっくり動くため、同じ分散でも波を作りやすい)。
  観測の波の質感は「中周波・中分散」であり、既知のマクロ変数の動き方と合わない
- **研究としての着地: 嵐は (i)実在し (ii)歴史の名場面と一致し (iii)グローバル金融
  サイクルの代理変数と方向整合だが (iv)その線形式では74〜85%が説明不能。
  「嵐の正体」はここで精密に定式化された未解決問題**として残る——
  反証可能な形で提示・棄却まで済んでいるので、これ自体が研究の成果物

## STORM-MONTHLY 設計 (2026-07-13・データ取得中に固定)

- データ: IMF ER (XDC_USD, 月末値, 全世界, 1970-2026)。取得: fetch_er_monthly.py
- **月次危機定義(年次LVルールの月次鏡映・事前固定)**: 12ヶ月減価率≥30% かつ
  12ヶ月前の同値より+10pp以上の加速 → その月は危機状態。
  発火(onset) = 危機状態かつ直前12ヶ月に危機状態なし
- **主検定(事前固定)**: 四半期の世界発火数(の系列, 1977Q1-2025Q4, n≈190) と
  四半期の観測要因(ドル12ヶ月変化・油価12ヶ月変化・FF水準・VIX)の相関。
  ラグ0〜4四半期まで全報告(つまみ食いなし)。n≈190で r=0.25 は p≈0.0006 —
  年次で方向だけだった示唆が有意になるかの検定
- 副検定: 四半期η̂(逆算, クランプ[-4,4])での同相関(頑健性)
- サニティ: 月次危機の発火数トップ月が既知の危機月と一致するか
  (1997年7-8月, 1994年12月-1995年1月, 1982年, 2008年10-11月)

## STORM-MONTHLY 結果 (2026-07-13) — **嵐の指紋、有意に到達**

- データ: 203カ国×月次、月次発火625件。サニティ: 発火集中月トップ =
  1981-05(ボルカーショック期)・**1994-01(CFAフラン一斉切下げ、18カ国同月)**・
  1985-02(ドルピーク)・**2008-10(リーマン)**・2015-08(人民元切下げ/新興国売り) —
  月次日付けは歴史の名場面をピンポイントで再現
- **主検定(四半期・自己相関調整後・全20セル報告中11有意)**:
  ドル12m高 r=+0.38**(同時) / VIX r=+0.37**(同時) / FF水準 r=+0.20〜0.25**(全ラグで持続) /
  油価12m安 r=-0.28**(同時)。**4要因すべて理論どおりの符号で有意**
- ラグ構造の読み: ドル・VIX・油は同四半期に効く(即効)、米金利の「水準」は
  全ラグで効く(高金利レジーム自体が危機多発期)。
  奇妙な1点: 油価lag4が正(+0.20)——資源ブーム→1年後バスト？未解釈のまま記録
- **年次46点では「方向のみ・非有意」だった嵐の正体が、四半期190点で有意な指紋になった:
  嵐 = ドル高 × 米高金利 × 資源安 × リスクオフ = グローバル金融サイクルの実証的確認**
- 未実施: 副検定(四半期η̂の逆算版)

## STORM-FORMULA-Q 結果 (2026-07-13) — **生成テスト合格、模型が観測変数で閉じた**

- GSI(世界ストレス指数) = z(ドル12m高)+z(FF水準)+z(資源12m安)+z(VIX) の等重平均(過剰適合回避
  のため重みは学習しない・事前固定)。年次入力=年内4四半期の平均
- **A(決定論・嵐=式のみ): D 3.19∈[2.18,3.86]✓ lag1 0.37∈[0.19,0.54]✓ → PASS**
  ——年次OLS式では棄却された生成テストを、四半期情報のz合成が通過
- B(式+AR残差): 必要残差σ=0.244(自由嵐は0.556) → **式が嵐の分散の約81%を運ぶ**
- 正直な注記: η̂への直接回帰のR²は0.112と低い(η̂自体の推定ノイズが大きい)。
  合格の意味は「点ごとの再現」でなく「変動の構造(振幅と持続)の再現」。
  また年次OLS版の失敗との差は (i)等重z合成の穏やかな振幅 (ii)VIX追加 (iii)対象年の違い
- **最終形: λ_{i,t} = σ( α·rank(x_i) + β·rank(P f_t)_i + δ + a + b·GSI_t [+ 小AR残差] )
  ——家計簿・貿易火事・観測可能な世界ストレスだけで、50年の危機史の質感が再現できる。
  自由パラメータとしての「嵐」は消滅(残差19%を除く)**
