# Phase 2 設計書: ネットワーク情報は「スカラーの穴」を埋めるか (2026-07-10)

> Phase 1 (notes/33) の確定結果: 単一スカラーは弱い(AUC≈0.6)・合成でも救えない(+0.017 n.s.)・
> 見逃しは軸の外(比率median 0.29)で中規模(減価46%)。共危機タイミングだけのネットワーク検証は2敗(null)。
> **未検証の残り: 本物のリンクデータ(貿易・銀行与信)を使った伝染チャネル。**

## RQ

国家間の実リンク(貿易・銀行与信)から作るネットワーク特徴は、
準備適正度スカラーが見逃す危機(FN 65%)を out-of-sample で捕捉できるか。

## データ(2026-07-10 に実在・入手可能性を裏取り済み)

| データ | 内容 | 入手 |
|---|---|---|
| BIS LBS (Locational Banking Statistics) | 報告国銀行→200カ国超の相手国への与信・負債(二国間・四半期) | data.bis.org から単一CSV一括DL可 |
| IMF IMTS (旧DOTS、2025-09改名) | 約220カ国の二国間輸出入(年次・月次) | data.imf.org 新ポータル/API |
| WDI パネル | Phase 1 で構築済み(113カ国・G-G・危機ラベル) | 取得済み |

注意: BIS報告国は先進国偏り。ただし**相手国(counterparty)側は200カ国超**をカバーし、
危機を起こす新興国は相手国側に現れるので「国Xへの与信総額・変化」は取れる。1970年代は薄い。

## 特徴量(最小セット・3つだけ。増やさない)

1. **隣人炎上指数**: Σ_j (リンク重み w_ij) × (国 j が t 年に危機) を w で正規化。貿易版と与信版
2. **sudden stop**: 国 i への与信総額の前年比変化率(急減=資金逃避)
3. **G-G×ネットワークの交互作用**: 比率が低くても隣人が燃えていたら、の項

## 検定プロトコル(結果を見る前に固定)

- 主検定: G-G単独 vs G-G+ネットワーク特徴。**OOS(pre-2000較正→post-2000)の AUC と lift**
- **成功基準(事前登録)**: OOS AUC 改善 ≥ +0.03 かつ 国ブロックブートストラップCIが0を除外
- 副検定: Phase 1 の FN 298件(スカラーが見逃した危機)に限定した捕捉率
- 規律: 数値は「再計算→docs/data/verified_results.txt に追記→cat」の1コマンド生出力のみ。捏造防止
- **null でも論文になる形にする**: 「実リンクの伝染情報でも埋まらない」なら
  Phase 1 の主張(残余は観測可能な次元の外)がさらに強化される。勝敗どちらも報告

## EXP1 結果 (2026-07-11・与信版・verified_results.txt末尾が正本)

- データ: BIS LBS一括CSV(17.7GB)から2パス抽出(残高S: 576,354行 / 為替調整フローF: 41,104行)。
  全報告国計は**1977年から**あり年代カバレッジ問題なし。スクリプト: `src/h_petri/empirical/phase2_exp1_bis.py`
- サンプル: n=2,666(BIS被覆で縮む)。train 882(危機220)/test 1,784(危機149)
- 単独AUC: **sudden_stop=0.517(ほぼ偶然)** / creditor_fire=0.547
- 主検定(ECDF+ロジスティック、サニティ通過: GG単独再現0.5890≈0.5891):
  GG単独 test 0.589 → +SS+CF 0.600、**delta=+0.011、CI[-0.001,+0.022]、p=0.060**
- **判定: 事前登録基準(+0.03かつCI 0除外)に不合格**。年次・与信集計のネットワーク特徴では穴は埋まらない
- 注記(post-hoc・信じる前に要独立検証): creditor_fire だけ脈がある——係数0.576、
  G-G盲域(比率≤1)のtestサブサンプルでAUC 0.594。多重比較の罠に注意
- 教訓: 初版ロジスティックは生値標準化で収束不良(GG係数が負)→ECDF変換で修正。
  **combining手法のサニティ(単独指標の再現)を必ず先に確認**
- 次: EXP2 = IMF IMTS貿易行列版の隣人炎上指数で同じ事前登録検定(基準は同じ+0.03)。
  SSの四半期版(年次で死んでいるだけの可能性)は優先度低で保留
