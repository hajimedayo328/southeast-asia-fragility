# 25. 層 (Sheaf) で「局所→大域」のリスク伝播を書く

**作成日**: 2026-05-25
**ステータス**: draft v1
**位置づけ**: ASEAN各国 (局所) のデータを sheaf として束ね、域内全体の構造リスクを
sheaf cohomology で **検出可能** にする。Ghrist applied sheaf theory + 本プロジェクト実例 = 新領域。

## §0 これが既存notesに書いてない理由

notes/02-24 は「全体構造」を直接書こうとしてた。
だが本プロジェクトの実データは **各国別** (局所)。
全体は「複数の局所を **整合的に束ねた** もの」として書ける方が自然。

層 (sheaf) は **局所→大域** を扱う唯一の categorical ツール。
これを本プロジェクトに当てると、1997年や Cloudflare 2025-11 が
**「sheaf cohomology の non-triviality」** として書ける。これは新規視点。

---

## §1 層 (sheaf) の最小定義

位相空間 X の上の sheaf F は、各開集合 U ⊂ X に対して
- 集合 (or 圏) `F(U)` を割り当てる関手
- 制限射 `res^U_V: F(U) → F(V)` (V ⊂ U) を持つ

そして **層条件 (sheaf condition)** を満たす:
> 局所セクション (`F(U_i)` の元) が重なり (`U_i ∩ U_j`) で整合的なら、
> **唯一の大域セクション** (`F(∪ U_i)` の元) に「貼り合わせ」られる

直感:
- 「各地の天気予報」が層なら、隣接地域で整合的なら全体の天気予報が決まる
- 整合的じゃない地域があるなら、貼り合わせ失敗 → 大域セクションが存在しない

---

## §2 本プロジェクトでの sheaf 構成

### 2.1 基本構成

位相空間: ASEAN域内 (各国を点とする離散位相 or 国境を境界とする)

層 `F`:
- 各国 U_i に対し、`F(U_i)` = 「国 U_i の Trust 値の集合」
- 制限射: 「国境地域での Trust 値の整合性」

これは Ghrist が "Elementary Applied Topology" で展開する **applied sheaf theory** の流儀。

### 2.2 sheaf cohomology の意味

- **H⁰(F)** = 大域セクションの集合 = 「域内全体で整合する Trust 状態」
- **H¹(F)** = 「貼り合わせの障害」の数 = **構造的リスク**

H¹(F) ≠ 0 ⇒ 「**局所では見えないが、域内全体に潜む不整合**」がある。
これが社会・経済システムでの **隠れたリスク** を categorical に検出する道具。

## §3 実例1: 1997 アジア通貨危機

### 3.1 1996年12月: H¹(F) = 0 (見かけは安定)

各国の Trust 値:
- タイ: ⊤_bank (USDペッグ + BIBF)
- 韓国: ⊤_bank (chaebol)
- インドネシア: ⊤_bank (民間銀行 + 国家)
- マレーシア: ⊤_bank

各国境地域での整合性: OK (USDペッグが共通 anchor)
→ H⁰(F) = ⊤_bank (域内全体の Trust)、H¹(F) = 0

### 3.2 1997年7月: H¹(F) が突然 ≠ 0

タイバーツ崩壊 → タイの Trust が ⊤_priv に降下。
ところが他の国は ⊤_bank のままだと **国境地域で不整合**:
- タイ-マレーシア境界: ⊤_priv | ⊤_bank ← 不整合
- タイ-インドネシア境界: ⊤_priv | ⊤_bank ← 不整合

→ **貼り合わせ失敗** = H¹(F) ≠ 0

この H¹(F) が「構造的に伝染可能なエッジ」の数を表す。
→ **「H¹(F) の急増が伝染の前兆 or 同時指標」** という新仮説。

**【検証済 2026-06-12 → 同時指標で確定】**: `src/h_petri/sheaf/h1_timeline.py` で
教科書的年表(THB変動 1997-07 → IDR 08 → KR 12 → MY資本規制 1998-09、順序は (c) 級)上の
H¹ を月次粒度で計算。**H¹ は発火前(1996-12〜1997-06)完全にフラットで、最初の上昇は
危機の発火と同時** → 「前兆」は不支持(前兆を主張するには危機に先行する入力信号が
要るが、本モデルには無い)。副産物: 1997-12 に H¹ が一旦縮む(全国が ⊤_priv に揃って
「低い水準で再整合」)— §3.3 の予想がモデルから自動再現された。
出力: `docs/data/h1_timeline.json`。

### 3.3 1998年: H¹(F) が一時的に縮小 (各国が個別に ⊤_priv 等に降下)

各国の Trust が低下して再び整合化:
- タイ: ⊤_priv
- 韓国: ⊤_priv
- インドネシア: ⊥ (banking system collapse)
- マレーシア: ⊤_priv (資本規制で部分的抑制)

→ H¹(F) は減るが、H⁰(F) が `⊥` 寄りに大幅低下 = 域内全体の Trust 崩壊。

### 3.4 マレーシア資本規制の sheaf 解釈

マレーシア 1998/9 資本規制 = 「**マレーシアの開集合を域内 sheaf から切り離す**」操作。
→ sheaf を **2つの連結成分** に分割 (マレーシア vs その他)。

これで:
- マレーシア局所では H¹ がリセットされる (孤立)
- マレーシア外の H¹ には影響なし

→ **「政治的決定で sheaf の topology が変わる」** = 国境の意味が変わる
これは categorical sheaf theory にない、本プロジェクト独自の社会的解釈。

## §4 実例2: Cloudflare 2025-11 障害

### 4.1 sheaf 構成 (空間 = AI サービス層)

位相空間: 世界の AI サービス (ChatGPT, Claude, Sora, 各種 API)
層 F:
- `F(U)` = サービス U の可用性 + Trust 値
- 制限射: サービス間の依存関係 (Cloudflare 経由なら同じ stalk)

### 4.2 2025-11-18 09:00 (障害前): H¹(F) = 0

すべてのサービスが正常稼働。Cloudflare 経由でも、各サービスは独立に Trust ⊤_priv。
H¹(F) = 0、H⁰(F) = ⊤_priv (全AI市場で並列に動く)。

### 4.3 09:30 (障害発火): H¹(F) が爆発

Cloudflare (共通CDN) が全AIサービスの共通 stalk → 設定ファイル障害 (Bot Management 設定) で **同時にダウン**:
- ChatGPT: ⊥
- Claude: ⊥
- Sora: ⊥

国境地域 (= サービス境界) で **互いに整合的に「壊れてる」** が、
H¹ の意味では「**共通 stalk の崩壊**」= H¹ の構造的爆発。

### 4.4 sheaf cohomology の visualizable な意味

> **「H¹(F) の急増 = 共通 stalk (= Cloudflare) の脆弱性が顕在化した瞬間」**

これは Cloudflare障害の **構造的な再記述**。 単なる「1社停止」じゃなく、
「sheaf の coherence が崩れる構造的事象」として書ける。

## §5 1997 と Cloudflare の構造的同型 (sheaf レベル)

両者は同じ sheaf-theoretic パターン:

| 観点 | 1997 AFC | Cloudflare 2025-11 |
|---|---|---|
| 共通 stalk | USDペッグ + 短期外貨債 | Cloudflare (共通CDN) |
| 局所セクション | 各国 backbone Trust | 各AIサービスの可用性 |
| 障害前 H¹ | 0 (見かけ整合) | 0 (全サービス正常) |
| 障害発火 | タイバーツ崩壊 | Cloudflare 設定ファイル障害 (Bot Management 設定) |
| 障害後 H¹ | 爆増 (域内伝染) | 爆増 (全AI同時死) |
| 回復 | 各国個別に Trust 再構築 | Cloudflare 修復で同時回復 |
| 時間スケール | 数年 | 約4時間 |

→ **両者は sheaf cohomology の同じ振る舞いを示す**。
これが notes/23 予言ペア2の数学的根拠。

## §6 sheaf による「予言可能性」の理論的根拠

### 6.1 主張

> **H¹(F) の time-derivative が「予言可能性」を測る**

直感:
- H¹ が大きい = 構造的にリスクが潜在
- H¹ の急増 = 危機の顕在化
- H¹ の慢性的上昇 = 「予言が実現する速度の加速」

これは notes/17 の「速度-集中度トレードオフ」を sheaf レベルで再記述した形。

### 6.2 検証可能性

ASEAN5 + 先進国の sheaf を構築して、
- 1997, 2008, 2010, 2022, 2025 各危機イベント前後の H¹(F) を計算
- ラグ縮小トレンド (notes/temporal §T8) との相関を見る

→ もし H¹(F) の time-derivative がラグと相関するなら、
**「H¹(F) を見れば次の危機が予測できる」** という強い主張になる。

これは政策設計に直接使える。
