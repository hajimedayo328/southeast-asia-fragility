# リードタイム完全版 + 新規点灯の情報量 (2026-07-20・実行前に固定)

notes/43の続き。「点きっぱなし型が支配的」の2つの疑問を裁く。

## EXP-A: リードタイムの右打ち切り解除 (記述・合否なし)

- 観測窓をonset前24ヶ月に拡大(q10点灯、モデル・ランキングはnotes/43と同一)
- 報告: 最初の点灯のリード分布(1〜24ヶ月・24で打ち切り)、
  「24ヶ月全部点灯していた」完全慢性型の割合、点灯月数シェアの分布

## EXP-B: 新規点灯 vs 慢性点灯 (事前登録)

「点きっぱなしの国」の警報は止まった時計かもしれない。点灯の**鮮度**に情報があるかを裁く。

- 定義(点灯=その月のq10入り):
  - streak(c,i) = iで終わる連続点灯月数
  - **新規点灯** = streak<=3 / **慢性点灯** = streak>=12 / 中間(4-11)は比較から除外・数のみ報告
- **主検定: P(6ヶ月内onset | 新規点灯) − P(6ヶ月内onset | 慢性点灯)。
  合格 = 差が正でCI(国ブロック)が0を除外** = 「新しい赤ほど危ない」
- 逆符号でCIが0を除外した場合は「慢性ほど危ない(=点きっぱなしは止まった時計ではなく
  長い前兆)」として、これも確定的な発見として記録(方向はどちらでも答えになる)
- 事前の読み: 五分五分。新規有利なら運用は「点灯の変化」を重視すべき。慢性有利なら
  リードタイム6ヶ月以上の「長い前兆」解釈が強まる

## 結果 (2026-07-20 実行・verified_results.txt正本)

### EXP-A: 真のリードタイムは中央値21ヶ月

- 窓24ヶ月で捕捉46/137件(34%)。最初の点灯: 中央値**21ヶ月前**、
  分布(1-6/7-12/13-18/19-24ヶ月前) = [7, 5, 8, 26]。24ヶ月全点灯=18件
- 捕捉されたonsetの点灯月数シェア中央値83% — 危機の前の2年間、ほぼ点きっぱなし
- 警報は「直前に鳴る」のではなく「危ない国が何年も光り続け、その一部がやがて落ちる」

### EXP-B: 逆符号で確定 — 慢性点灯ほど危ない

| 点灯の鮮度 | n | 的中率(6ヶ月内onset) |
|---|---|---|
| 新規(streak<=3) | 797 | 3.5% |
| 中間(4-11) | 1003 | 5.3% |
| 慢性(>=12) | 1231 | **9.6%** |

差(新規−慢性) = −0.061、CI[−0.115, −0.021]。事前登録どおり逆符号CIゼロ除外=確定。
単調勾配(3.5→5.3→9.6%)。新規点灯の的中率3.5%は基礎率2.9%とほぼ同じ=
**点いた瞬間にはほぼ情報がない**。慢性赤は基礎率の3.3倍。

### 読みと注意点

- 「点きっぱなし=止まった時計」は誤り。**赤の持続こそが情報**。運用は点灯の変化でなく
  持続月数を重視すべき(streakを第3の材料にする追加検定は次の候補)
- 注意1: 慢性優位の一部は「スペルの加齢」かもしれない。赤スペルがいずれ危機で終わるなら、
  スペルの深い月ほど機械的に終わり(危機)に近い。「持続が情報を足す」のか
  「待ち時間の構造」なのかはこの検定では区別できない
- 注意2: データ欠落月でstreakが人工的にリセットされ慢性が新規に誤分類される分は、
  差を薄める方向(保守的)に働く
- 注意3: 新規/慢性の閾値(3/12)は事前固定だが恣意的。単調勾配が出ているので
  閾値の選び方に結論は依存しないと見るが、別の切り方での確認はしていない
