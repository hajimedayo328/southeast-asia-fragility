## 出発点 — notes 28 が残した唯一の穴

notes 28 は §5.5 の5カ国で **偽陰性(マレーシア)** を示せたが、5カ国全員が危機当事国のため
**偽陽性(比率>1 なのに危機が来ない)** は測れないと明記した。埋めるには非危機国・年のパネルが要る。
本ノートはそれを実データで構築する。

## データ(実取得・再現可能)

|---|---|---|---|
| 短期外債/総準備(%) | `DT.DOD.DSTC.IR.ZS` | シグナル(=G-G比率×100) | **113カ国・4402国年・1975-2022** |
| 対ドル為替(期中平均) | `PA.NUS.FCRF` | 機械的通貨暴落の判定 | 212カ国 |

World Bank API から実取得しキャッシュ(2026-06-15)。捏造ではない、再実行で再現可能。

### 最重要の正直さ — このパネルは §5.5 と同じ数字ではない
- §5.5 は **BIS 基準・1997年6月末**(RBA RDP9805)。本パネルは **WDI/DRS・年次・年末**。出所が違う。
- **韓国・マレーシアは WDI のこの系列に欠損**(当時 DRS 非報告)。§5.5 の5カ国中、本パネルに居るのは
  **ID/TH/PH のみ**。重なる年でも値は食い違う(例: フィリピン 1996年末 0.68 ≈ RBA の 0.7 だが、
  WDI 1997年末は危機発生後で 1.35)。
- ∴ 本パネルは「§5.5 の数値の拡張」ではなく「**G-G ルール自体を一貫系列で大規模検証**」したもの。

## 方法(事前登録 — 着手前に固定、p-hacking 封じ)

- **母集団**: WDI/DRS の全 113カ国・全年。国も年も後から選ばない。
- **シグナル**: 比率 = `DT.DOD.DSTC.IR.ZS`/100、`比率 > θ` で発火。主 θ=1.0(**名付けられた
  Guidotti–Greenspan 閾値**、著者調整でない)。感度 θ∈{0.5,1.0,1.5,2.0}。
- **危機(2系統を併記)**: 為替から機械的に通貨暴落を再現。年減価 ≥ D かつ前年比加速 ≥ A。
  - **FR**(Frankel–Rose 1996): D=25%, A=10pp
  - **LV**(Laeven–Valencia ルール): D=30%, A=10pp(主)
  期中平均為替は**年央危機(1997年7月のバーツ)を2暦年に分割**して各年を閾値割れさせるため、
  同じ閾値を **1年変化と2年累積変化の両方**に当て、どちらかが満たせばクラッシュとする
  (新たなチューニング無し)。危機は**オンセット(連続クラッシュの初年)**で1件と数える。
- **平穏フィルタ(早期警戒の作法)**: シグナルは危機**前**に平穏時に出るべきもの。その年自体が
  クラッシュ年の国年は評価から除外(危機の渦中の発火を偽警報に数えると過大評価になる。
  例: アルゼンチン1980年代前半)。
- **結果判定**: シグナル年 t に対し、窓 (t, t+k] にクラッシュのオンセットがあれば的中。主 k=2年、
  感度 k∈{1,2,3}。為替が t-1..t+k を覆う国年のみ採用(「危機なし」を欠損で捏造しない)。
- **指標**: 混同行列 + FPR=FP/(FP+TN) + 偽警報率=FP/(FP+TP) + recall=TP/(TP+FN) +
  KLR の noise-to-signal=FPR/recall + ベースレート + lift=精度/ベースレート。

### 検出器のサニティ(教科書的危機を捉えるか, LV)
TH[1998] / ID[…1998] / KR[…1998…] / MX[…1995…] / AR[…2002…] / RU[1998,2015] /
BR[…1999…] / TR[…2001,2018,2022…] — いずれも捕捉、過剰検出なし。

## 結果(主: LV, θ=1.0, k=2)

平穏国年 **3451**(危機中 627・為替窓欠損 324 を除外)。

| | 危機が来た | 来ない | |
|---|---|---|---|
| **比率>1(発火)** | TP=163 | FP=487 | 発火 650 |
| **比率≤1** | FN=298 | TN=2503 | |

- **偽警報率 = 487/650 = 75%** ← §5.6 が欲した「比率>1 だが危機なし」の率
- **FPR(平時の誤発火) = 16.3%**、**recall = 35.4%**(危機の **65% を取り逃す**)
- **noise-to-signal = 0.461**(<1)、**lift = 1.88**(発火で2年内危機確率 13%→25%)
- FR ルールでもほぼ同じ(偽警報 72%、NtS 0.476、lift 1.79)

### 感度(頑健)
θ↑で偽警報率↓・recall↓(精度/再現トレードオフ)、k↑で偽警報率↓・ベースレート↑、と単調。
全 24 セル(θ×k×2ルール)で **NtS≈0.34–0.65、lift≈1.5–1.9** ——
**常に情報はある(NtS<1, lift>1)が、常に偽警報が支配的**。

## 解釈 — 称揚でも全否定でもない

- **本物だが弱いシグナル**: NtS<1・lift1.88。発火は危機確率をほぼ倍に上げる。
  → Frankel–Saravelos「準備指標で最有効」と整合(指標に向きはある)。
- **偽警報が支配(75%)・recall 低(35%)**: 危機の 65%(298件)は **比率≤1 のまま来た** ——
  これは notes 28 の**マレーシア型偽陰性をパネル規模で**見たもの(別チャネル発の危機を取り逃す)。
  → Berg–Borensztein–Pattillo「単一閾値 EWS は誤報が常」と整合。
- 偽陽性の実例(平穏期の誤発火)はアルゼンチンのカレンシーボード期(1991–2001、高い短期外債/準備
  でもペッグ維持で 2002 まで暴落せず)などに典型的に現れる。

## 結論 — §5.6 を「数字つき」に

- §5.6 は「専用の偽陽性率を文献から借りられない」と書いていた。本パネルで **真の偽陽性率を実測**
  (偽警報率 75% / FPR 16% / NtS 0.46 / lift 1.88)し、**「数字が無い」を「測った数字」に置換**。
- 結論の向きは変わらず、むしろ**根拠が強まる**: G-G 比率は「有用な向きを持つが、偽警報支配で
  recall の低い、単一チャネルの弱い早期警戒シグナル」。§5.6 の慎重な格付けは**実測で正当化**された。

## 正直な限界

- WDI/DRS ≠ §5.5 の BIS 基準(韓国・マレーシア欠損、重なる値も相違)。本パネルは**ルールの検証**で
  あって §5.5 の数値の再現ではない。
- 危機判定は FR/LV の**閾値ルールの再現**であり、L&V の**キュレート済みリストの逐語転記ではない**
  (端ケースで差。IMF 旧 API は廃止・新 API は要認証で本環境から検証不能だったため、転記による
  捏造リスクを避けて機械再現を採用)。
- 期中平均為替ゆえ年央危機の**日付は近似**(タイは 1998 に計上)。1年/2年併用で取りこぼしは回避。
- 国年は系列相関あり(実効 N は件数より小)。資本規制で回避された危機(マレーシア1998)は機械的
  暴落ルールでは見えない —— まさに単一チャネルの限界。
