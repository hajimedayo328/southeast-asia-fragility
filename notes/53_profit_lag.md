# PROFIT-LAG: 供給到着は利益を物理ラグどおりに潰すか (2026-07-22・実行前固定)

TTB-HORIZON(notes/51)の続き。株価は先回りして落ちる(検定済み)が、利益は先回りできない。
コブウェブの実物側が正しければ、投資ブーム後の**利益の谷のタイミング k* が TTB に比例**するはず。

- データ: BEA NIPA 6.16系(業種別企業利益, API取得) + 3.7ESIブーム年(notes/51と同一) + Koeva TTB
- 手順: notes/51と同一構成で、結果変数だけ「業種利益の前年比成長」に差し替え。
  k*_profit = ブーム後k=1..5の平均利益成長が最低の年
- **主検定: Spearman rho(TTB, k*_profit) > 0 かつ 並べ替えp<0.05**
- 読み: PASSなら「実物はラグ法則に従い、株価だけが先回りする」の完全な鎖。
  FAILなら「利益ですらラグが読めない=集計業種レベルではコブウェブは観測不能」

## 結果 (2026-07-22): 判定不能 (n=3で検定力ゼロ)

- 利益6.16Dが1998年開始のため、ブーム×5年先まで揃う業種が3つしか残らなかった
  (rho=-0.500, p=1.000 は3点の順位相関であり情報なし)
- **不合格ではなく「このデータでは検定不能」として記録**。歴史の長いSIC版(6.16B/C)は
  APIの同型呼び出しでは返らず(要Year明示の再試行)、救済路として記録
- 現状の鎖: 商品=成立(文献) / 株価=先回りで消える(TTB-HORIZON) / 利益=未決着

## 救済路の結末 (2026-07-22)

- 6.16B/CはBEAが**予算制約で廃止**(APIエラー201で確認)。API経由の長期利益データは死路
- 残る唯一の道: BEAの discontinued-data-tables アーカイブ(静的ファイル)から手動発掘
- 現時点の確定: **PROFIT-LAGは「データ制約で未決着」のまま閉じる**。
  鎖: 商品=成立 / 利益=未決着(データなし) / 株価=先回りで消滅

## v2事前登録 (2026-09-04・実行前固定): SIC歴史版で中間輪を復活

- 利益代理 = 営業余剰系列のスプライス: 72SIC PTI(1947-87) + 87SIC PTI(1987-97) +
  NAICS GOS(GDPbyIndustry Table6, 1997-2024)。**成長率は各ヴィンテージ内でのみ計算**(水準の継ぎ目跨ぎ禁止)
- ブーム: notes/51と同一(3.7ESI・自分史上位1/4・20年履歴・1968-2019)
- k*_profit = ブーム後k=1..5の平均営業余剰成長の最低年(各kに最低8ブーム)
- **主検定: Spearman rho(TTB, k*_profit)>0 かつ 並べ替えp<0.05**(変更なし)
- マッピングはログ出力を目視確認してから本計算(revision_log教訓)

## v2結果 (2026-09-04・verified_results.txt正本): 不合格で鎖が完結

- SIC歴史版XLS(GDPbyInd_VA_SIC.xls)発掘で営業余剰を1947-2024にスプライス成功
  (コード名はPTIでなくGOSだった=命名バグ1件修正、マッピングはログ目視確認済み)
- **n=12業種、Spearman rho(TTB, k*_profit)=−0.224、p=0.783 → 明確な不合格**
- 鎖の最終形: **商品価格=成立(文献) / 業種利益=不成立 / 株価=不成立**
- 読み: コブウェブのラグ法則は「単一財の価格」でしか観測できない。業種集計の利益は
  製品ミックス・価格と数量の相殺で法則が溶け、株価はさらに先回りが加わる。
  動画の法則の適用範囲は「単一財・現物価格」に限定される——これがこの探索の最終回答
