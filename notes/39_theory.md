# 理論ノート: 順位不変性の定理と、攻撃/崩壊の分離の理論的基礎 (2026-07-16)

> 上位レベル差分④への着手。実証で観察した2つの規則性を、証明可能な命題と
> 標準理論への接続として固定する。

## 1. 順位不変性の定理 (実証第5章「水準は腐る・順位は残る」の形式化)

**設定**: 各期 t に n カ国のスコア s = (s_1,…,s_n) ∈ R^n (相異なる値と仮定) を観測し、
警報規則 S: R^n → 2^{[n]} が監視対象の集合 S(s) を選ぶ。
時代効果を「共通の狭義単調増加変換」としてモデル化する:
観測されるのは s̃_i = h_t(s_i)、h_t: R→R は狭義単調増加だが**未知**。

**定義**: S が**ドリフト不変** ⟺ 任意の狭義単調増加 h と任意の s に対し
S(h(s_1),…,h(s_n)) = S(s_1,…,s_n)。

**定理 1**: S がドリフト不変 ⟺ S は順位ベクトル rank(s) のみを通じて s に依存する。

*証明*:
(⇐) 狭義単調増加変換は順位を保存するので明らか。
(⇒) rank(s) = rank(s') なる任意の s, s' を取る。同順位で並べ替えた値を
s_(1) < … < s_(n)、s'_(1) < … < s'_(n) とし、各 i で h(s_(i)) = s'_(i) となる
区分線形な狭義単調増加関数 h を作る(隣接点間を線形補間し、両端は勾配1で延長)。
このとき h(s) = s'(成分ごと)。ドリフト不変性より S(s) = S(h(s)) = S(s')。
よって S は順位のみの関数。∎

**系 1.1 (分位点警報の不変性)**: 「上位 q% に発火」は rank のみの関数なのでドリフト不変。

**系 1.2 (固定閾値の空洞化)**: 固定閾値規則 A_τ(s) = {i: s_i > τ} は順位のみの関数では
ないため(n≥2 で反例が作れる)ドリフト不変でない。さらに任意の τ とスコア分布に対し、
h(x) = x − c (c 十分大) を取れば A_τ(h(s)) = ∅。
**= どんな指標で作っても、固定閾値警報は適当な共通ドリフトで完全に沈黙させられる。**
実証対応: G-G の θ=1 規則の recall 44%→20%、自作固定閾値警報の死(ALARM実験)。

**注意(誠実性)**: 定理は「順位づけの正確さ(判別力)が時間不変」とは主張しない。
主張は「共通単調ドリフトに対する頑健性は順位規則だけが持つ」まで。判別力自体の
安定は実証事実(OOSでlift 1.42→1.90)であって定理の帰結ではない。

## 2. 攻撃と崩壊の分離: グローバルゲームへの接続 (スケッチ・定理ではない)

実証事実(EMP-DATING): 貿易火事は**崩壊**(FX 12ヶ月30%)を予告するが、
**圧力イベント**(EMP攻撃、防衛成功含む)は予告しない。

Morris-Shin 型の体制攻撃モデルで自然に整理できる:
- 国 i の基礎体力 θ_i,t (準備・競争力)。投機家は公的シグナル(嵐 GSI_t)と
  私的シグナルを見て攻撃を決める。攻撃成功 ⟺ 攻撃者の質量 > θ_i,t
- **攻撃の発生**は公的シグナル(嵐)に強く駆動される(グローバルゲームの比較静学:
  公的シグナルの悪化は全域で攻撃閾値を動かす) → EMPイベントは嵐の領分
- **崩壊の発生**は θ_i,t が実際に低いことを要求する。貿易チャネルは
  θ_i,t の侵食項として入る: 相手国の切下げ → 実質競争力の低下 →
  θ_i,t+1 = θ_i,t − κ·(P f)_i + … (ゆっくり・実体経済)
- 帰結: (Pf) は θ の侵食を通じて「攻撃されたときに耐えられるか」を決める
  = **崩壊の予測子**。攻撃のタイミング自体は嵐と私的情報のノイズ
  = (Pf) と直交。**実証の分離と整合**

これを命題化するには攻撃強度と崩壊確率の結合分布の仮定が要る(未着手)。
卒論レベルでは「実証パターンが標準理論の予測と整合する」の記述で十分。
定理1は自前の貢献としてそのまま使える(初等的だが、警報設計の文脈で
明示的に述べた文献は確認していない——執筆時に要サーベイ)。

## 2.5 理論スケッチへの実証フィードバック (ATTACK-ANATOMY, 2026-07-17)

予測を2本検定した:
- **(a) 嵐→攻撃: 的中**。GSI×攻撃件数 r=+0.394**(lag0) — 本プログラム中最強の単相関。
  攻撃のタイミングは公的シグナル(嵐)と同期する。グローバルゲームの比較静学と整合
- **(b) 攻撃→崩壊: 予測の半分が外れた(重要)**。攻撃486件中53%が12ヶ月以内に崩壊。
  その分水嶺は:
  | 予測子(攻撃前年) | AUC | 係数 |
  |---|---|---|
  | 家計簿GG(貯金) | **0.521(ほぼ無力)** | 0.128 |
  | 貿易火事TF | **0.612** | 1.349 |
  **「攻撃されたとき、貯金は救ってくれない。救うか殺すかを分けるのは貿易近傍の火事」**。
  スケッチの素朴な読み(θ=準備が防衛力)は要修正。候補の解釈:
  1. **選択効果**: 攻撃者は既にGGを見て標的を選ぶ→攻撃条件付きサンプルではGGのレンジが
     圧縮され条件付き判別力が消える(切断による減衰)。グローバルゲームとは実は整合
  2. 攻撃後の帰趨は実体経済の圧力(競争力侵食=TF)が決める: 準備は数週間で燃やせるが
     侵食は持続する
  - 限界: GGは年次(攻撃前年末)の粗い値。攻撃時点の月次準備での再検定が本来の防衛力テスト
    → **実施済み(ATTACK-DEFENSE)**: 攻撃直前月の準備(輸入月数)でも AUC 0.47-0.48 = 無力。
      データの粗さではない

## 2.6 準備(貯金)の役割の完全解剖 — 三部作 (2026-07-17)

| 問い | 検定 | 結果 |
|---|---|---|
| **抑止力**: 貯金薄い国ほど攻撃されるか | 非攻撃時4.8万国月→3ヶ月内攻撃 | **AUC 0.630 CI[0.60,0.67] あり** |
| **防衛力**: 攻撃されたら貯金が救うか | 攻撃543件→12ヶ月内崩壊 | **AUC 0.47-0.52 なし**(月次でも) |
| **生存の分水嶺**: 何が倒れるかを決めるか | 同上 | **貿易火事 AUC 0.61 係数1.35** |

> **貯金は攻撃を防ぐが、攻撃されたら救わない。救うか殺すかは貿易近傍の火事が決める。**

理論的整合: グローバルゲームの選択チャネルの実証 — 攻撃者は事前に準備を織り込んで
標的を選ぶため、攻撃条件付きでは準備の情報は使い尽くされている(切断による減衰)。
政策的含意(皮肉): 1997年後の集団的な準備積み増し(v4のグローバル学習)は攻撃の「頻度」を
下げたが(抑止)、攻撃された場合の「生存率」は買えていない。生存を買うのは
貿易構造の分散であり、それは準備と違って一朝一夕に積めない。

## 2.7 新規性監査 (2026-07-18・敵対的サーチ、書誌は検索確認・全文未読)

**主張A「貯金は防ぐが救わない」**: 
- killer priorに最接近するのは **Kraay (2003, J. Int. Econ.)**: 300超の投機攻撃で
  「高金利防衛は攻撃の帰結と無関係」。攻撃条件付きの帰結分析という**ジャンル自体が確立済み**
  (NBER章 "Does It Pay to Defend against a Speculative Attack?" 等)。
  抑止側(準備が危機の発生を予測)も標準的知見(Frankel-Saravelos等)
- ただし発見した範囲では、(i)**準備の「水準」**が攻撃条件付きで生存を予測しないこと、
  (ii)生存の実際のマージンが**貿易近傍**であること、(iii)三部作としての統一的分解、は未発見。
  文献側も「防衛成功は識別困難で危機定義から漏れる」と明言しており、EMPで攻撃を
  識別した上での検定はこの穴を突いている

  特定した」— Kraayを冒頭で引く義務。単独の大発見ではなく拡張+マージン特定として提示
