# v4: 準備の内生化 = 真のペトリネット化 (2026-07-15・実行前に固定)

## 動機

v1-v3 の模型は「準備(=G-G比 x)の推移」を**観測値で外生固定**し、危機状態 f の伝播だけを
内生化していた。v4 では x も内生化する = ペトリネット本来の姿:
**トークン=外貨準備、遷移=投機攻撃(トークンを消費)、補充=政策反応**。

これが通れば、Phase 1 の主要発見「**空洞化**」(2000年以降みんなが貯金して警報が鳴らなくなった)
が、模型の**外から与えた事実**ではなく**模型が生成する帰結**になる。= Goodhart効果の機構モデル。

## 観測事実 (2026-07-15・実データ)

| 年 | G-G比 中央値 | >1 の割合 | onset数 |
|---|---|---|---|
| 1982 | 0.636 | 41.9% | 52 |
| 1992 | 0.695 | 41.0% | 12 |
| 1997 | 0.502 | 26.7% | 9 |
| 2002 | 0.408 | 26.5% | 11 |
| 2007 | 0.262 | 11.5% | 0 |
| 2022 | 0.259 | 8.7% | 5 |

**1997年を境に中央値が半減(0.5→0.26)、>1の国が42%→11%に激減。これが空洞化の正体。**

**決定的な観測**: 危機を経験した国の危機後3年のG-G比変化 = 中央値 **−0.009**(ほぼゼロ)。
非危機国年の年次変化 = 中央値 −0.0002。
→ **「自国が痛い目に遭ったから積んだ」では空洞化を説明できない**。
  空洞化は個別学習ではなく**集団的・同時的な体制転換**の産物という仮説が立つ。

## 模型 v4 (実行前に固定)

状態: 各国の log x_{i,t} (G-G比の対数) と f_{i,t} (危機状態)

1. **攻撃(遷移)**: λ_{i,t} = σ( α·rank_t(x) + β·rank_t(Pf) + δ + b_gsi·GSI_t )  ← v3と同一
2. **準備の動力学(新規)**:
   Δlog x_{i,t+1} = −( a + b·own_crisis_{i,t} + c·world_crisis_t ) + ε_{i,t}
   - a: 基礎トレンド
   - b: **ローカル学習**(自国が危機を経験→積む)
   - c: **グローバル学習**(世界の危機発生率を見て→皆が積む)
   - ε: 特異ショック(推定残差のsdでガウス)

## 推定と検証 (事前固定)

- 推定: **pre-2000のみ**で (a,b,c) を Δlog x の OLS で推定。σ_ε は残差sd
- シミュレーション: 1977年の観測初期分布から、x と f を**同時に内生**で2022年まで走らせる×300回
- **検証(較正外・事前固定)**: post-2000 の
  (v1) G-G比の中央値の推移(2007年・2022年の値が90%帯に入るか)
  (v2) 「>1の割合」の推移(同上)
  (v3) 年間onset数の平均(同上)
- **対決(主目的)**: c=0 に固定した「ローカル学習のみ」模型が同じ検証を通るか。
  **通らなければ「空洞化にはグローバル学習が必要」= Goodhart効果は個別学習でなく集団転換**

## 失敗の定義

- フル模型が(v1)(v2)を外す → 「この動力学クラスでは空洞化を生成できない」と記録。
  外生要因(先進国の資本供給・IMF政策・中国の台頭等)が必要という示唆
- フルもローカルも通る → グローバル学習は不要。空洞化は基礎トレンドで足りる

## v4 / v4.1 結果 (2026-07-15) — 中央値の空洞化は生成できた。分散の縮小は未達

### 推定値そのものが発見 (pre-2000, n=1,785国年)

| 係数 | 値 | 意味 |
|---|---|---|
| **グローバル学習 c** | **+0.342** | 世界の危機率を見て皆が積む |
| ローカル学習 b | +0.058 | 自国が焼けて積む |
| 平均回帰 d | +0.060 | 危険な国ほど強く積む(標的化調整) |
| 基礎トレンド a | +0.008 | ほぼゼロ |

**「他人の火事を見て学ぶ」係数は「自分が焼けて学ぶ」の約6倍。**
しかも自国危機は稀(年5%程度の国しか経験しない)のに対し世界危機率は全員に効くため、
集計的な寄与差はさらに大きい。**空洞化は個別学習でなく集団的な社会的学習の産物**。

### 生成テスト (較正に使っていない post-2000 の4項目)

| 模型 | 通過 | 中央値2007/2022 | >1割合2007/2022 |
|---|---|---|---|
| **フル(学習+平均回帰)** | **2/4** | ✓ [0.236,0.658] / ✓ [0.212,0.644] | ✗ [0.238,0.429] / ✗ |
| 対照A(グローバル学習なし) | **0/4** | ✗ 高すぎる[0.371,1.011] | ✗ |
| 対照B(平均回帰なし=v4) | **0/4** | ✗ 下げすぎ[0.040,0.253] | ✗ |

**主結論: 中央値の空洞化(0.65→0.26)を生成するには、グローバル学習と平均回帰の
両方が必要。片方を外すと0/4に崩壊する。** = 空洞化の機構が特定された。

### 未達と診断(正直に)

**「>1の国の割合」は全模型が外す**(模型24-43% vs 観測11%)。原因は明確:
現実では分布の**幅そのものが縮んだ**(p75: 1982年 2.736 → 2007年 0.585)が、
模型は特異ショックの分散 σ_ε=0.72 を固定しているため右裾が厚いまま。
→ **空洞化は「中央値の低下」+「分散の縮小」の二層構造**であり、後者は未説明。
   次の一手: σ を内生化(危険な国ほど高ボラ、または時代とともに縮小)。
   これは「資本市場が新興国に対して寛容になった/選別的になった」という別の物語を要求する
