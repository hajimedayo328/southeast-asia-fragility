# 市場グラフ × 通貨危機の接続 (2026-07-15・実行前に固定)

## 経緯

指導教員(賈先生)の示唆: 「(公式統計の信頼性より)先にやった market-graph と接続してみたら」。
market-graph-research (別プロジェクト, 2021-2026, 41銘柄日次) の CLAIM:
**「市場ネットワークの位相的穴(H₁のL¹ノルム)は外因性ショックに先行して上昇する」**
(event study n=12, pre-event +4.3%, p=0.0018)。

本研究(通貨危機)の未解決点:
**嵐 η_t (危機の波を駆動する共通ショック)は、GSI(ドル・米金利・資源・VIXのz合成=スカラー)で
約81%しか説明できず、19%が未同定**。年次の線形式は生成テストで棄却された経緯もある。

## 仮説 (この接続の核心)

> **嵐の未同定成分は「市場ネットワークの構造」に宿る。**
> スカラー(価格の水準・変化)では捉えられない構造情報 = market-graph の主張そのもの。
> 因果の絵: 市場ネットの構造のほつれ → 世界の嵐 → 新興国通貨危機の波

これは本研究の主題(スカラーの限界→ネットワーク構造)が**二階層で再帰**する形:
- 第1階層(済): 国の危機予測で 借金÷貯金(スカラー) → 貿易火事(ネットワーク)
- 第2階層(本実験): 嵐の測定で GSI(スカラー) → 市場グラフ構造(ネットワーク)

## 問題と解決

market-graph の期間は 2021-2026 で、本研究の嵐(1977-2022)と**ほぼ重ならない**。
→ **market-graph の手法(相関→Mantegna距離→グラフ→構造不変量)を長期マクロ資産に適用**し、
「歴史的マーケットグラフ」(1974-2025, 月次)を自前で構築する。

### 構造の作り方 (market-graph の流儀を踏襲)

- 月次リターン → **36ヶ月ローリング相関** ρ_ij (各月末)
- Mantegna距離 d_ij = sqrt(2(1-ρ_ij))
- グラフ: ρ_ij > 0.5 を辺とする(閾値は market-graph の 0.7 が日次・個別銘柄向けのため、
  月次マクロ資産用に 0.5 とし**実行前に固定**。頑健性として 0.4/0.6 も全報告)

### 指標 (主指標は事前選択・後から選ばない)

- **主指標: β₁ = E − V + C** (第一ベッチ数 = 独立サイクル数 = 「構造の穴」)
  ← market-graph の CLAIM (H₁ が先行) の長期・純Python版
- 副次(全報告): density, max_k_core, isolated_count, MST総長, 最大クリークサイズ

## 検定 (事前固定)

土壌は STORM-MONTHLY と同じ**四半期の世界発火数**(月次危機定義, 1977Q1-2025Q4, n≈190)。
年次η̂(44点)ではなく四半期を使うのは検出力のため。

1. **記述**: 各構造指標 と 発火数 の相関(ラグ0〜4四半期・全セル報告・自己相関調整n_eff)
2. **主検定**: 発火数 ~ GSI(現行) vs 発火数 ~ GSI + β₁ の R² 改善。
   ブートストラップ(年ブロック)でCIを出す。**成功 = R²改善のCIが0を除外**
3. **サニティ**: 1998, 2008, 2020 など既知のショック期に β₁ が動くか(顔検査)

## 失敗の定義も先に書く

- 主検定が不合格 → 「市場構造は嵐の未同定19%を説明しない」= market-graph の主張は
  (少なくとも長期マクロ・通貨危機の文脈では)接続しない、と正直に記録。
  嵐の残りは市場構造の外(政治・伝染心理・データ限界)にある
- 合格 → 2つのプロジェクトが1つの因果連鎖で繋がる。卒論の骨格候補になる

## 結果 (2026-07-15) — **接続せず。完全なnull**

構築物: 歴史的マーケットグラフ 1977-2026・月次595点・11マクロノード・36ヶ月窓・閾値0.5。
サニティは妥当(β1: 2008Q4=5.7, 2020Q1=3.7, 1998Q3=1.0 = 危機期に穴が開く)。

**⚠️ 事前登録した合格基準そのものに欠陥があった(重要な自己修正)**
「ΔR²のブートストラップCIが0を除外」は、**ΔR²が変数追加で数学的に必ず≥0** になるため
自動的に成立してしまう。初回実行は「PASS」と表示されたが**この判定は無効**。
正しくブロック順列検定(年ブロックでβ1を入替、B=2000)でやり直した:

| 項目 | 値 |
|---|---|
| R²(GSI) | 0.273 |
| R²(GSI+β1) | 0.273 |
| **ΔR²** | **+0.0000** (帰無中央値 +0.0021 より小さい) |
| **p** | **0.963 → FAIL** |
| β1単独R² | 0.000、係数 −0.007 |
| 記述相関(β1/density/k-core/isolated × ラグ0-4, 全20セル) | **全て |r|<0.08** |

**読み(なぜ繋がらなかったか)**:
market-graph の CLAIM は「日次・41銘柄・ショックの**15日前**にH₁が上昇」。
本研究の嵐は**四半期〜年**スケール。**時間スケールが2桁違う**。
36ヶ月ローリング窓は年次スケールの構造しか見ておらず、market-graph が捉えている
「数週間のほつれ」は原理的に映らない。**"market-graph が間違い"ではなく"別の時間スケールの現象"**。

**この null が持つ価値**:
1. 嵐の未同定19%は「マクロ資産の相関構造」の外にある(候補: 資本フロー実データ・政治・
   新興国個別の市場ミクロ構造)
2. 2プロジェクトを繋ぐなら、接続点は**嵐(年次)ではなく個別危機イベント(日次)**であるべき。
   例: 危機の月次onsetの前後15日で market-graph の日次L¹が動くか(=イベントスタディの
   対象を「貿易政策ショック」から「新興国通貨危機」に差し替える)。
   ただし market-graph のデータは2021-2026のみ→この期間の危機(トルコ・アルゼンチン・
   エジプト・ナイジェリア等)に限定される。**これが次の自然な実験**
3. 自分の事前登録基準の欠陥を実行後に発見・自己修正した記録(統計設計の教訓:
   入れ子モデルの改善量は非負なので、必ず順列検定かF検定で裁くこと)

## 第2の接続点(日次イベントスタディ)も null (2026-07-15・BRIDGE-EVENT)

上の反省「接続点は嵐(年次)でなく個別危機イベント(日次)であるべき」を実行。
market-graph の event_study.py の設計をそのまま踏襲し、**イベントだけを差し替え**:
元「貿易政策・地政学ショック 12件」→ 本研究の**新興国通貨危機 onset 13件**
(2023-12トルコ, 2024-10エジプト, 2024-07エチオピア, 2025-12アルゼンチン, 2026-02ボリビア等)。
pre-event=[-15,-1]日の平均 vs baseline、順列検定(偽イベント同数, B=5000)。

| 指標 | 変化 | p | 判定 |
|---|---|---|---|
| **‖H₁‖₁ (主指標)** | **−0.0%** | 0.564 | **FAIL** |
| 同 window=20/40/60日 | −2.4% / −1.7% / +5.4% | 0.73/0.71/0.24 | 全てFAIL |
| [副次] avg_clustering | +5.3% | 0.048 | Bonferroni閾値0.006に届かず |
| [副次] max_k_core | +5.0% | 0.067 | n.s. |
| [副次] density | +4.6% | 0.109 | n.s. |
| [副次] num_communities | −22.5% | 0.973 | n.s.(減少方向) |
| [副次] isolated_count | −40.3% | 0.969 | n.s.(減少方向) |

**方向の一貫性は見える(が有意でない)**: 危機前に density↑ clustering↑ k-core↑
communities↓ isolated↓ = **市場が「一枚岩化」する**方向で8指標中5つが揃う。
だが多重比較補正後はどれも有意でない。**null として扱う**。

## 2度の接続実験からの結論(暫定)

**market-graph と通貨危機研究は、少なくともこの2つの形では接続しない。**
- 年次(嵐 × マクロ資産グラフ構造): p=0.963
- 日次(危機イベント × 位相的穴): p=0.564

**解釈(本研究の主結論と整合)**: market-graph が見ているのは**先進国市場の構造**
(S&P・VIX・主要通貨・米株)。本研究の結論は「嵐(グローバル金融サイクル)が波を作り、
**貿易ネットワークが犠牲者を選ぶ**」。つまり**「誰が倒れるか」の情報は先進国市場の構造には
無く、貿易ネットワークにある**——2つの実験はこの主張の裏側からの確認になっている。
グローバル市場はガーナやエチオピアの危機を事前に織り込まない(織り込むほど関心がない)。

**残る可能性(未実施・優先度低)**: market-graph に新興国通貨(USDTRY/EURTRY/USDHUF)が
3本入っている。EMサブグラフの局所構造なら映る可能性はあるが、3ノードでは構造指標が定義困難。
深追いは筋が悪いと判断し、接続実験はここで打ち止めとする。
