# MEMORY-COBWEB: メモリ単一財でラグ法則の年表検定 (2026-09-04・実行前固定)

動画の主戦場そのもの: メモリ価格は「ブームの約2年後(工場TTB)に潰れる」を歴史で答え合わせ。

## 設計 (データの中身を見る前に固定)

- 価格系列: BLSメモリ製品PPI(2015年廃止・FRED経由)を第一候補、無ければ
  半導体製造業PPI(PCU334413334413)。年次平均→前年比成長
- **趨勢処理**: 半導体PPIは品質調整で恒常的に下落するため、成長率から
  拡大窓中央値(最低8年)を引いた「相対成長」で全て判定(これをしないと自動合格の欠陥)
- ブーム年 = 相対成長が自分史(拡大窓)の上位1/4。各ブームの後k=1..4の相対成長を計測
- **主検定: (i) k=2の平均相対成長 < 0 かつ (ii) 符号検定(ブーム横断でk=2が負の割合>半分)
  p<0.05。合格 = 両方成立**
- 全報告: k=1,3,4のパス、谷ラグk*の分布(TTB≈2年予測との整合)
- 事前の読み: やや強気。シリコンサイクルは業界の常識で、単一財価格なら
  コブウェブが見えるはず。不合格なら「品質調整PPIではサイクルが消える」という
  測定上の教訓として記録

## 結果 (2026-09-04・verified_results.txt正本): 不合格(計器の敗北として記録)

- メモリ専用PPIは2015年廃止・別ID候補も全滅 → 事前登録の第2候補
  (半導体製造業PPI 1967-2025)で実行
- booms=5(1983,84,2013,15,17)、k=2平均+0.004、符号検定p=0.812 → **FAIL**
- **ただし読みは「法則の否定」ではなく「計器の敗北」**: 品質調整された集計PPIは
  ほぼ単調下落で、96/01/08/19年の有名なDRAM暴落がブームとして検出すらされない。
  メモリのサイクルはロジック・マイクロと混ぜられ希釈されている
- 単一財のきれいな検定にはDRAM契約価格(DRAMeXchange=有償)が必要。
  「商品では成立」の根拠は自前検定ではなく文献(豚・卵・船)のまま——正直にそう書く

## 動画発プログラムの総括

| 検定対象 | 判定 | 根拠 |
|---|---|---|
| 単一財価格(豚・卵・船) | 成立 | 文献確立(コブウェブ/Greenwood-Hanson) |
| 単一財価格(メモリ・自前) | 判定不能 | 公開計器が鈍い(専用PPI廃止) |
| 業種集計の利益 | 不成立 | PROFIT-LAG v2 (rho−0.224) |
| 業種の株式リターン | 不成立 | TTB-HORIZON (rho+0.275 p=0.145) |
| 通貨危機の再発 | 不成立 | 忘却サイクル(打切り人工物検出込み) |

結論: 「足りないものは余る」の法則が観測できるのは単一財の現物価格まで。
集計・金融市場・マクロ危機へ持ち出すと、希釈と先回りで消える。
