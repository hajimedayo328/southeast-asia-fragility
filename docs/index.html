§ 01 — 枠組み

圏論的枠組み: 便利と不可視コストの随伴

「便利と代償のペア」を、随伴という構造で精密に書き直してみる試み。

抗生物質は楽に病気を治せるけど、使いすぎると 耐性菌が出る。AI に頼ると楽になるけど、自分で考える力が落ちる。自動運転は楽だけど、緊急時に反応できなくなる。

これらは別々の話に見えて、似た構造に見える。「便利を取ると、どこかに見えない代償がつきやすい」。圏論の「随伴 (ずいはん)」は、L (便利な方) と R (代償の方) をペアで扱う道具。本プロジェクトはこの随伴を枠組みとして借りて、便利と代償をセットで可視化する。

正直な注釈: 「便利があれば必ず代償がある」を数学的に証明したわけではない。各ドメインで随伴が実在することは示していない。随伴は「観察されるペア構造を整理する見方」として採用しているだけ。"必然"を売りにはしない (これは本プロジェクトの方針)。

圏論の随伴 L ⊣ R は、左随伴 (自由・便利) と 右随伴 (制約・コスト) をペアで扱う構造。 本プロジェクトではこれを「便利 L と不可視コスト R を同時に追跡する記法」として使う (L だけ・R だけを別々に語るのではなく、必ずセットで見る、という規律を与えてくれる)。

§ 02 — 事例 · 災害都市

災害時の都市インフラ脆弱性

沖積平野の3大都市 (ジャカルタ・マニラ・ハノイ) が抱える共通の脆弱性。

ジャカルタ・マニラ・ハノイ。東南アジアの代表的な大都市は、全部 「沖積平野 (ちゅうせきへいや)」 — 川が運んできた土でできた、低くて平らな土地 — の上にある。地下水を汲み上げすぎてジャカルタは 年5cm 沈んでる。

そこに集中して人が住んで、効率の良いコンパクトな街を作ってる。便利。でも、台風や洪水で 1本の橋や 1個のポンプ場が止まると、街全体が分断される。

フィリピンは 「世界災害リスク指数」で 16年連続 1位。台風が年20個来る。1件の災害で何兆円も損失が出る。「効率的にしたら脆くなった」という、東南アジアの典型的な例。

仮説C1 · 見える層

過去20年でどの国に災害が多かったか

フィリピンとインドネシアが圧倒的に多い (400件超)。海に面した国 (PH/ID) は台風・地震・火山。内陸国 (LA/KH) は洪水・干ばつ中心で件数も少ない。地理が災害profileを決めてる。

ASEAN10は海洋ASEAN (PH/ID) と 内陸ASEAN (LA/KH) で災害の傾向が大きく異なる。 台風通り道 (PH/VN) と火山列 (PH/ID) が物理的に決まっている。

仮説C2 · 見えない層

「人が首都に集中してる国」ほど災害被害が大きい?

仮説としては「集中都市=効率的だが、災害で1点が壊れたら全滅」のはず。ただしデータ点が10カ国しかなく、明確な傾向はまだ出てない。今後の検証ポイント。

最大都市の人口集中度が高い国ほど、災害1件あたりの経済被害が大きい (仮説)。 コンパクト都市の便利 (L) が、災害時の脆弱性 (R) として顕在化する。

§ 03 — ASEAN10カ国 概観

ASEAN10の比較指標

経済規模・都市集中・電気アクセス・通信普及・宗教・植民地経路の同時マップ。

東南アジア (ASEAN) は たった10カ国でめちゃくちゃ多様。シンガポール (1人あたり GDP 850万円) と ミャンマー (12万円) で 70倍の差。仏教国・イスラム国・キリスト教国・社会主義国が同じ地域に混在してる。

面白いのは 「どの国に支配されてたか」で、今のインフラ普及が決まってる こと。イギリス植民地だった国 (シンガポール・マレーシア・ブルネイ) はネット普及率 95% 超。フランス植民地だった国 (ベトナム・カンボジア・ラオス) は 60-78%。100年前の歴史が今も効いてる。

そしてラオスは 異常値 — 電気は 100% 通ってるのに、モバイル契約が他国の半分しかない。これが何を意味するかは、まだ分かってない。

仮説E1 · 100年前の影響

「どの国に支配されてたか」が今のネット普及率を決めてる?

イギリス植民地だった国 (SG/MY/BN) はネット普及率95%超。フランス領 (VN/KH/LA) は60-78%。100年前の法制度・教育制度の差が現代のインフラ整備に効いている可能性。

イギリス圏 (SG/MY/BN) はネット普及率95%超、フランス圏 (VN/KH/LA) は60-78%帯。 法制度の連続性が長期インフラ投資に効いている可能性。

ラオスだけ異常値: 電気は全国に通ってるのにモバイルが少ない

§ 04 — KEY FINDINGS · 主要発見

本プロジェクトで見えた 5つのこと

「東南アジアの脆弱性は先進国の予言」を支える 5 つの具体的発見。発見5が実データで一番正直。

発見 1 · 律速逆転 (越境統合の代償)

同じ要素集合でも、合成方向で律速が逆転する

ASEAN4 backbone を並列 (⊗) に並べると最強 (⊤_pub, Bakong) で律速。 でも越境統合 (▷) すると最弱 (⊤_priv, GCash) で律速。 「ASEAN域内決済統合を進めると、構造的に脆弱になる」 という反直観的予言。

数学的根拠: Ghrist-Gould-Lopez 2024 "Lattice-Valued Bottleneck Duality"。 本プロジェクトは Open Petri Net (Baez-Master 2018) の文脈に翻訳し、ASEAN モバイル金融で実コード検証 (Petri net タブ)。

発見 2 · 1997アジア通貨危機との整合的解釈

「⊤_priv が ⊤_pub を演じる」状態の崩壊

1997年以前、東南アジア各国の銀行システムは USDペッグで「⊤_pub」に見えた。 でも実態は外貨建て短期民間債務 = ⊤_priv。 タイの崩壊が ▷ で繋がった域内全体に meet律速で伝染。 「⊤_priv が ⊤_pub を演じてた」状態の崩壊 — 評価の浅さが暴露される瞬間。

マレーシアは資本規制 (▷ チャネル切断) で被害を抑制 → 律速逆転の枠組みと整合的な事後解釈 (演繹的検証ではない)。詳細は 時間軸タブ §T6。

発見 3 · AI依存に同じ構造が現れる

ChatGPT vs Claude vs Llama も、Bakong vs GCash vs PayNow と同型

LLM の backbone を Heyting値で分類すると: 政府AI (仮想) = ⊤_pub、Llama (オープン) = ⊤_bank、ChatGPT/Claude (民間) = ⊤_priv。 multi-agent システムは meet律速で脆くなる。 東南アジアモバイル金融の構造が、AI時代の先進国に既に現れている。

2025年11月の ChatGPT/Claude/Gemini 同時障害は、独立企業のはずが共通インフラ依存で同時崩壊 = M-Pesa 障害と同型構造。詳細は notes/18。

発見 4 · 圏論本気適用 3 層 (モナド / 層 / 翻訳関手)

「予言」を 3 つの圏論レイヤーでコード実装

予言の構造を 3 つの圏論的層 でコードに落とした: ① Writer H モナド — 720 順列すべてで同じ ⊤_pub に収束 (∨ の半束則からの帰結で、実装が正しく満たすことの確認)、 ② Čech H¹ 層 — 1997 AFC で H¹ が 0→4→6 と階段上昇、Cloudflare 2025-11 で H⁰(meet) が ⊤_priv→⊥ 崩壊、 ③ 翻訳関手 F: 𝓒_EA → 𝓒_Dev — 5 予言ペアを strict / quasi / partial / lax で自然性分類。

これで「予言の強度 = 関手の自然性の度合い」が 数値で測れる位置取りになった。 Floridi-Jia-Tohmé 2025 の Kan 拡張ツールセットがそのまま転用可能。 実装は Petri net §P6 (Sheaf) / §P7 (Monad) / 時間軸 §T10 (翻訳関手)。

発見 5 · 脆弱性はスカラーでなく構造に乗る (実データ・一番正直)

普及率で予測できない。支配するのは圏論的な「型」

核の主張の一番素朴な形を実データに当てたら 外れた — 3回とも: 包摂水準 ↔ 集中度 ρ ≈ −0.08、mobile money 水準 ρ ≈ +0.18、 普及速度(Findex 2017→2021) ρ ≈ −0.05。 backbone の型は包摂水準の分散を η² ≈ 0.004(≒0%)しか説明しない = 型とスカラーは直交。 → 脆弱性を支配するのは普及率(スカラー)ではなく 圏論的な構造(型)。

出典付きの実障害イベントで「どう壊れるか」を見ると、故障モードは2つの構造軸に分解される: 運用トポロジ(単一社 → 全停止 / 共有レール → 銀行別に分散)と Heyting バックストップ型(民間 ⊤_priv → 利用者が損失 / 中銀・銀行 → system が吸収)。 どちらもスカラー普及率と無関係。圏論はここで元を取る — 「どう壊れ、誰が払うか」の不変量を、金融包摂統計が見えない所で名指しできる。

域外テスト(インド UPI / ブラジル Pix / ケニア)での精密化: 「速い AND 分散」はアプリのレベルでは存在する(Pix は史上最速 — 1年で成人の67% — なのに支配的アプリなし)。でもレールのレベルでは例外なし: 速い普及は世界中どこでも単一共有レール(Pix=中央銀行 / UPI=NPCI / M-Pesa=Safaricom)に乗ってる。
→ 「stalk(共有の土台)を無くす」という選択肢はメニューに存在しない。 選べるのは stalk の後ろに誰が立つか(⊤_pub / コンソーシアム / ⊤_priv)だけ。 これが本プロジェクトの sheaf 分析・予言ペア(M-Pesa↔Cloudflare)と1本の線で繋がる。

正直な限界: n=8(国)・障害イベントは各セル数件で統計でなく図示レベル。 この n では2軸を分離しきれない。型間の障害頻度は主張しない(Bakong=0件は中銀の自己報告 + 英語報道過小 = 開示バイアス)。主張は「how/who(モード)」だけで「how often」は外す。 域外テストも限界あり: 速度の単位がケース間で完全には揃わない・Pix のアプリ別シェアは未公表(設計からの推論)・ UPI トップアプリ 47.7% は閾値50%に対し borderline。 コード: src/h_petri/empirical/ (データは World Bank Findex API で再検証・mobile money は三重検証、集中度は中信頼)。

§ 05 — 統合と結論

東南アジアは先進国の予言である

同じ構造、別のスケール、同じ未来。

東南アジアで起きてることをまとめると 「便利を取って、見えない代償を払ってる」 という1つのパターンに収束する。送金が便利になったら 1社依存になり、街がコンパクトになったら災害で詰むようになり、海外送金で食えるようになったら他国の景気に振り回されるようになった。

これって日本やアメリカの未来でもある。AI に頼ると思考力が落ちる、GAFA に依存するとシステム障害で全滅、自動運転で運転スキルを失う。同じ「便利の裏の代償」が、先進国でこれから加速する。

つまり 東南アジアは「先進国の予言者」。彼らが先に経験した脆さは、5〜10年後の日本で起きること。先進国は「援助する側」じゃなく、「東南アジアから学ぶ側」だってのが、このプロジェクトの主張。

ASEAN10で見えてきたのは:

  • L (便利) が暴走する国ほど、R (不可視コスト) も同時に増える
  • backbone タイプ (Platform / Central Bank / Bank / Telco) で脆弱性メカニズムが変わる
  • 都市集中度・仕送り依存度・植民地経路が、不可視コストの「形」を規定する
  • Laosのような異常値が、フレームワークの限界点を教えてくれる

先進国 (日本・米国・EU) への転用

先進国は東南アジアと逆方向で同じ構造を再生産している:

  • AI依存 = LLMルート関手で人間判断をスキップ → 判断力の不可視コスト
  • プラットフォーム経済 = GAFA backbone集中 → 単一企業崩壊リスク
  • 自動運転・自動化 = 物理労働スキップ → スキル喪失コスト
  • 少子化対応の移民労働 = 送出国依存 = 受け入れ側のリープフロッグ

東南アジアは「リープフロッグ」と呼ばれる現象を世界で最も濃く実演している実験場。 その実験室で起きていることを記述する道具が圏論なら、 同じ道具で先進国の盲点 (AI依存・プラットフォーム集中) も読み替えられる。

§ 06 — この数字はどこまで信じていい?

正確性の格付け (a) / (b) / (c)

研究の見栄えより、「どこが本物でどこが仮定か」を先に開示する。

このサイトの数字は、全部が同じ重さじゃない。AIが書いた研究は、もっともらしい嘘を混ぜがち(実際このプロジェクトでも、存在しない論文や間違った障害データを2回検出・修正した)。だから「どの数字がどれだけ信頼できるか」を3段階で明示する。

段階意味このプロジェクトでの例
(a) 危険 AIが直接でっち上げた値・固有名・引用 検出して全削除した(架空論文 Curry-Krishnan、誤った Cloudflare 障害データ)
(b) 中間 プログラムは正しく計算したが、入力の値は著者が手で置いた。計算は正確でも前提は主観的 予言ペアの strict/lax/broken 判定、sheaf の H¹(辺・各時点の値が手置き)
(c) 頼れる ロジック自体を独立検証 or 入力が出典付きの事実 backbone の信頼レベル(規制事実から導出)、Kan拡張の随伴(全数チェックで検証)、圏の公理

結論: 土台(backbone 分類)と数学的な検証部分は (c)。 予言ペアの強弱スペクトラムは (b) — 「割当てを固定すれば一意に決まる」レベルで、 データで証明された強弱ではない。この区別を曖昧にしないことが、この研究で一番大事にしている所。 詳細は notes/27 §7。
