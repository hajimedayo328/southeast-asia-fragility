§ 01 — FRAMEWORK

圏論的枠組み: 便利と不可視コストの随伴

数学的に対称な構造は、社会現象の非対称な振る舞いを正確に映す。

抗生物質は楽に病気を治せるけど、使いすぎると 耐性菌が出る。AI に頼ると楽になるけど、自分で考える力が落ちる。自動運転は楽だけど、緊急時に反応できなくなる。

これらは別々の話に見えて、実は 全部同じ構造。「便利を取ると、必ずどこかに見えない代償がついてくる」。これを数学では「随伴 (ずいはん)」と呼ぶ。L (便利な方) と R (代償の方) は必ずペアで現れて、片方だけは存在できない。

つまり 「便利が存在する=代償が存在する」が数学的な必然。これは「気をつけよう」じゃなくて、「物理法則に近い決まり事」として扱える。

圏論の随伴 L ⊣ R は、左随伴 (自由・便利) と 右随伴 (制約・コスト) を必ずペアで現出させる構造。 片方だけ存在することはない。これにより、「便利が存在すること」は「コストが存在すること」と数学的に同値になる。

§ 02 — CASE A · MOBILE MONEY

モバイル金融のリープフロッグと集中度

ASEAN10カ国でモバイルマネー普及が一気に進む。便利の裏側に何が貼り付くか。

日本は「銀行口座作る → ATM/振込で送金」が普通。だけど東南アジアの多くの国では、そもそも銀行口座を作らずに、いきなりスマホでお金を送る ことが普通になってる。ベトナムの MoMo、フィリピンの GCash、カンボジアの Bakong とか。

これを「リープフロッグ (蛙跳び)」と呼ぶ。先進国が辿った道を飛ばして、いきなり最先端に行く現象。

便利な反面、「その1社が止まると国民の送金が全滅する」みたいな脆さも一緒に増えてる。下のグラフはそれを実データで見たもの。

§ 03 — CASE A · BACKBONE TYPES

信頼のbackboneタイプ別 構造リスク

「誰の信頼を借りているか」で脆弱性のパターンが変わる。

「誰がそのお金の仕組みを支えてるか」で、リスクの形が全然違う。

例: ① 中央銀行 (国) が直接運営 (タイの PromptPay、カンボジアの Bakong) → 政治変動に弱いが分散的。② 民間プラットフォーム 1社が独占 (フィリピンの GCash 85%、ベトナムの MoMo) → 早いが、その会社崩壊で全滅。③ 銀行コンソーシアム (シンガポールの PayNow) → 安定だが導入遅い。④ 電話会社 (M-Pesa 型) → ASEANではほぼ絶滅。

同じ「モバイル送金」でも、誰が backbone (バックボーン=骨格) かで、何が起きたときに崩れるかが全く違う。

ASEAN10の決済backbone分類

§ 04 — CASE B · REMITTANCE

仕送りグラフ: 個人スケールから国経済まで

バイト先で聞いた1人の話が、世界の送金ネットワークの縮図になる。

日本でバイトしてるベトナム人やフィリピン人が、毎月の給料の一部を母国の家族に送ってる。これを「仕送り (remittance、リミッタンス)」って言う。

これがバカにならない規模で、フィリピンは GDP の 8.9% が仕送り収入。つまり国全体の経済の1割が「海外で働く家族からの送金」で成り立ってる。カンボジア 6.5%、ミャンマー 5.5% も同じ構造。

便利な仕組み (国境越え送金、技能実習制度) があるおかげで成立してるけど、もし日本の景気が悪くなったり、入管制度が厳しくなったりすると、東南アジアの村が直撃する。便利の裏に「他国依存」というコストが貼り付いてる例。

§ 05 — CASE C · DISASTER

災害時の都市インフラ脆弱性

沖積平野の3大都市 (ジャカルタ・マニラ・ハノイ) が抱える共通の脆弱性。

ジャカルタ・マニラ・ハノイ。東南アジアの代表的な大都市は、全部 「沖積平野 (ちゅうせきへいや)」 — 川が運んできた土でできた、低くて平らな土地 — の上にある。地下水を汲み上げすぎてジャカルタは 年5cm 沈んでる。

そこに集中して人が住んで、効率の良いコンパクトな街を作ってる。便利。でも、台風や洪水で 1本の橋や 1個のポンプ場が止まると、街全体が分断される。

フィリピンは 「世界災害リスク指数」で 16年連続 1位。台風が年20個来る。1件の災害で何兆円も損失が出る。「効率的にしたら脆くなった」という、東南アジアの典型的な例。

災害頻度の地理勾配

ASEAN10は海洋ASEAN (PH/ID) と 内陸ASEAN (LA/KH) で災害profileが大きく異なる。 台風通り道 (PH/VN) と火山列 (PH/ID) が物理的に決まっている。

§ 06 — ASEAN10 OVERVIEW

ASEAN10の比較指標

経済規模・都市集中・電気アクセス・通信普及・宗教・植民地経路の同時マップ。

東南アジア (ASEAN) は たった10カ国でめちゃくちゃ多様。シンガポール (1人あたり GDP 850万円) と ミャンマー (12万円) で 70倍の差。仏教国・イスラム国・キリスト教国・社会主義国が同じ地域に混在してる。

面白いのは 「どの国に支配されてたか」で、今のインフラ普及が決まってる こと。イギリス植民地だった国 (シンガポール・マレーシア・ブルネイ) はネット普及率 95% 超。フランス植民地だった国 (ベトナム・カンボジア・ラオス) は 60-78%。100年前の歴史が今も効いてる。

そしてラオスは 異常値 — 電気は 100% 通ってるのに、モバイル契約が他国の半分しかない。これが何を意味するかは、まだ分かってない。

§ 07 — SYNTHESIS

東南アジアは先進国の予言である

同じ構造、別のスケール、同じ未来。

東南アジアで起きてることをまとめると 「便利を取って、見えない代償を払ってる」 という1つのパターンに収束する。送金が便利になったら 1社依存になり、街がコンパクトになったら災害で詰むようになり、海外送金で食えるようになったら他国の景気に振り回されるようになった。

これって日本やアメリカの未来でもある。AI に頼ると思考力が落ちる、GAFA に依存するとシステム障害で全滅、自動運転で運転スキルを失う。同じ「便利の裏の代償」が、先進国でこれから加速する。

つまり 東南アジアは「先進国の予言者」。彼らが先に経験した脆さは、5〜10年後の日本で起きること。先進国は「援助する側」じゃなく、「東南アジアから学ぶ側」だってのが、このプロジェクトの主張。

ASEAN10で見えてきたのは:

  • L (便利) が暴走する国ほど、R (不可視コスト) も同時に増える
  • backbone タイプ (Platform / Central Bank / Bank / Telco) で脆弱性メカニズムが変わる
  • 都市集中度・仕送り依存度・植民地経路が、不可視コストの「形」を規定する
  • Laosのような異常値が、フレームワークの限界点を教えてくれる

先進国 (日本・米国・EU) への転用

先進国は東南アジアと逆方向で同じ構造を再生産している:

  • AI依存 = LLMルート関手で人間判断をスキップ → 判断力の不可視コスト
  • プラットフォーム経済 = GAFA backbone集中 → 単一企業崩壊リスク
  • 自動運転・自動化 = 物理労働スキップ → スキル喪失コスト
  • 少子化対応の移民労働 = 送出国依存 = 受け入れ側のリープフロッグ

東南アジアは「リープフロッグ」と呼ばれる現象を世界で最も濃く実演している実験場。 その実験室で起きていることを記述する道具が圏論なら、 同じ道具で先進国の盲点 (AI依存・プラットフォーム集中) も読み替えられる。

このプロジェクトの主張 (1文)

圏論の随伴は数学的に対称な構造であり、 したがって「便利」と「不可視コスト」は必ずペアで現れる。
東南アジアを観察することは、先進国の脆弱性を予測することである。
